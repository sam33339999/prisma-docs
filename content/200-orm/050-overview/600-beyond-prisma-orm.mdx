作為 Prisma ORM 使用者，您已經體驗到型別安全的資料庫查詢和直觀的資料建模的強大功能。然而，在擴展正式環境應用程式時，會出現新的挑戰。隨著應用程式的成熟，您將開始遇到連線池的複雜性，或需要找到有效快取常見查詢的方法。

與其花費寶貴的時間克服這些挑戰，不如讓我們探索 Prisma 如何透過擴展 ORM 的功能來幫助您的應用程式成長。

## 使用 Prisma Accelerate 提升應用程式效能

隨著應用程式的擴展，您可能需要工具來有效處理增加的流量。這通常涉及實作連線池來管理資料庫連線，以及快取策略來減少資料庫負載並改善回應時間。Prisma Accelerate 在單一解決方案中滿足這些需求，無需設定和管理單獨的基礎設施。

Prisma Accelerate 對於部署到無伺服器和邊緣環境（也稱為 Function-as-a-Service）的應用程式特別有用，因為這些部署方式會導致建立的連線數比傳統長期執行的應用程式多出數個數量級。對於這些應用程式，Prisma Accelerate 還有一個額外的好處，就是從第一天起就保護您的資料庫，並讓您的應用程式在線上運行，[無論您遇到多大的流量](https://www.prisma.io/blog/saving-black-friday-with-connection-pooling)。

試試看 [Accelerate 速度測試](https://accelerate-speed-test.prisma.io/)，了解可能的效果。

### 使用連線池改善查詢效能

將您的連線池放置在 15 個以上的全球區域之一，最小化資料庫操作的延遲。啟用跨無伺服器和邊緣環境的高效能分散式工作負載。

### 使用快取減少查詢延遲和資料庫負載

在 300 多個全球存在點快取查詢結果。Accelerate 擴展了您的 Prisma Client，在每個查詢的基礎上提供直觀、精細的快取模式控制，例如 `ttl` 和 `swr`。

### 使用受管理的基礎設施處理擴展流量

擴展到每天數百萬次查詢，無需更改基礎設施。有效管理資料庫連線，並以更少的資源服務更多使用者。

### 立即開始使用 Accelerate

Accelerate 透過 `@prisma/extension-accelerate` 客戶端擴充功能與您的 Prisma ORM 專案無縫整合。透過我們的[設定指南](/accelerate/getting-started)快速開始，並立即存取完整的邊緣環境支援、連線池和全球快取。

```tsx
import { PrismaClient } from '../prisma/generated/client'
import { withAccelerate } from '@prisma/extension-accelerate'

// 1. Extend your Prisma Client with the Accelerate extension
const prisma = new PrismaClient().$extends(withAccelerate())

// 2. (Optionally) add cache to your Prisma queries
const users = await prisma.user.findMany({
  cacheStrategy: {
    ttl: 30, // Consider data fresh for 30 seconds
    swr: 60  // Serve stale data for up to 60 seconds while fetching fresh data
  }
})
```

要查看更多範例，請造訪我們的[範例儲存庫](https://github.com/prisma/prisma-examples)，或使用 `npx try-prisma` 自己試試。
