PostgreSQL 資料來源連接器將 Prisma ORM 連接到 [PostgreSQL](https://www.postgresql.org/) 資料庫伺服器。

預設情況下,PostgreSQL 連接器包含負責連接到資料庫的資料庫驅動程式。你可以使用[驅動程式轉接器](/orm/overview/databases/database-drivers#driver-adapters)(預覽版)從 Prisma Client 使用 JavaScript 資料庫驅動程式連接到資料庫。

:::info

需要立即取得 Postgres 實例?

使用 [Prisma Postgres](https://www.prisma.io/postgres?utm_source=docs&utm_campaign=postgresql),你可以在三次點擊內在裸機上運行資料庫。連接池、查詢快取和自動備份全部包含在內。[造訪控制台](https://console.prisma.io?utm_source=docs&utm_campaign=postgresql)立即開始。

想要更快速地開始使用 Prisma Postgres?只需在終端機中執行 `npx prisma init --db`。🚀

:::

## 範例

要連接到 PostgreSQL 資料庫伺服器,你需要在 [Prisma schema](/orm/prisma-schema) 中設定一個 [`datasource`](/orm/prisma-schema/overview/data-sources) 區塊:

```prisma file=schema.prisma
datasource db {
  provider = "postgresql"
}
```

`datasource` 區塊指定 `postgresql` 資料來源連接器。

在 Prisma ORM 7 中,資料庫連接 URL 在 [`prisma.config.ts`](/orm/reference/prisma-config-reference) 中設定:

```typescript file=prisma.config.ts
import { defineConfig, env } from 'prisma/config'
import 'dotenv/config'

export default defineConfig({
  schema: 'prisma/schema.prisma',
  datasource: {
    url: env('DATABASE_URL'),
  },
})
```

此設定使用[環境變數](/orm/prisma-schema/overview#accessing-environment-variables-from-the-schema)來提供資料庫連接 URL。

## 使用 `node-postgres` 驅動程式

從 [`v5.4.0`](https://github.com/prisma/prisma/releases/tag/5.4.0) 開始,你可以使用 Prisma ORM 配合 JavaScript 生態系統中的資料庫驅動程式(而不是使用 Prisma ORM 的內建驅動程式)。你可以透過使用[驅動程式轉接器](/orm/overview/databases/database-drivers)來實現這一點。

對於 PostgreSQL,[`node-postgres`](https://node-postgres.com) (`pg`) 是 JavaScript 生態系統中最受歡迎的驅動程式之一。它可以與任何透過 TCP 存取的 PostgreSQL 資料庫一起使用。

本節說明如何與 Prisma ORM 和 `@prisma/adapter-pg` 驅動程式轉接器一起使用。

### 1. 安裝相依性

首先,安裝 Prisma ORM 的 `pg` 驅動程式轉接器:

```terminal
npm install @prisma/adapter-pg
```

### 2. 使用驅動程式轉接器實例化 Prisma Client

現在,當你實例化 Prisma Client 時,需要將 Prisma ORM 的驅動程式轉接器實例傳遞給 `PrismaClient` 建構函式:

```ts
import 'dotenv/config'
import { PrismaPg } from '@prisma/adapter-pg'
import { PrismaClient } from '../generated/prisma/client'

const connectionString = `${process.env.DATABASE_URL}`

const adapter = new PrismaPg({ connectionString })
const prisma = new PrismaClient({ adapter })
```

請注意,此程式碼需要將 `DATABASE_URL` 環境變數設定為你的 PostgreSQL 連接字串。你可以在下面了解更多關於連接字串的資訊。

### 注意事項

#### 指定 PostgreSQL schema

你可以在實例化 `PrismaPg` 時傳入 `schema` 選項來指定 [PostgreSQL schema](https://www.postgresql.org/docs/current/ddl-schemas.html):

```ts
const adapter = new PrismaPg(
  { connectionString },
  { schema: 'myPostgresSchema' }
)
```

## 連接詳情

### 連接 URL

Prisma ORM 遵循 [PostgreSQL 官方指南](https://www.postgresql.org/docs/current/libpq-connect.html#LIBPQ-CONNSTRING)指定的連接 URL 格式,但不支援所有參數,並包含額外的參數,例如 `schema`。以下是 PostgreSQL 連接 URL 所需元件的概述:

![PostgreSQL 連接 URL 的結構](./postgresql-connection-string.png)

#### 基礎 URL 和路徑

以下是使用大寫字母佔位符值的_基礎 URL_ 和_路徑_結構範例:

```
postgresql://USER:PASSWORD@HOST:PORT/DATABASE
```

以下元件組成了資料庫的_基礎 URL_,它們始終是必需的:

| 名稱     | 佔位符      | 描述                                                                                                     |
| :------- | :---------- | :------------------------------------------------------------------------------------------------------ |
| Host     | `HOST`      | 資料庫伺服器的 IP 位址/網域,例如 `localhost`                                                              |
| Port     | `PORT`      | 資料庫伺服器運行的埠號,例如 `5432`                                                                        |
| User     | `USER`      | 資料庫使用者的名稱,例如 `janedoe`                                                                         |
| Password | `PASSWORD`  | 資料庫使用者的密碼                                                                                        |
| Database | `DATABASE`  | 你想使用的[資料庫](https://www.postgresql.org/docs/12/manage-ag-overview.html)名稱,例如 `mydb`           |

:::info

你必須對[特殊字元進行百分比編碼](/orm/reference/connection-urls#special-characters)。

:::

#### 參數

連接 URL 也可以接受參數。以下是使用大寫字母佔位符值表示三個_參數_的相同範例:

```
postgresql://USER:PASSWORD@HOST:PORT/DATABASE?KEY1=VALUE&KEY2=VALUE&KEY3=VALUE
```

可以使用以下參數:

| 參數名稱                | 必需     | 預設值                  | 描述                                                                                                                                                                |
| :--------------------- | :------- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `schema`               | **是**   | `public`               | 你想使用的 [schema](https://www.postgresql.org/docs/12/ddl-schemas.html) 名稱,例如 `myschema`                                                                       |
| `connection_limit`     | 否       | `num_cpus * 2 + 1`     | [連接池](/orm/prisma-client/setup-and-configuration/databases-connections/connection-pool)的最大大小(Prisma ORM v6 及更早版本)                                    |
| `connect_timeout`      | 否       | `5`                    | 等待新連接開啟的最大秒數,`0` 表示無逾時                                                                                                                               |
| `pool_timeout`         | 否       | `10`                   | 等待從連接池獲取新連接的最大秒數,`0` 表示無逾時                                                                                                                        |
| `sslmode`              | 否       | `prefer`               | 設定是否使用 TLS。可能的值:`prefer`、`disable`、`require`                                                                                                            |
| `sslcert`              | 否       |                        | 伺服器憑證的路徑。憑證路徑[相對於 `./prisma` 資料夾解析](/orm/prisma-schema/overview/data-sources#securing-database-connections)                                     |
| `sslrootcert`          | 否       |                        | 根憑證的路徑。憑證路徑[相對於 `./prisma` 資料夾解析](/orm/prisma-schema/overview/data-sources#securing-database-connections)                                        |
| `sslidentity`          | 否       |                        | PKCS12 憑證的路徑                                                                                                                                                   |
| `sslpassword`          | 否       |                        | 用於保護 PKCS12 檔案的密碼                                                                                                                                          |
| `sslaccept`            | 否       | `accept_invalid_certs` | 設定是否檢查憑證中缺失的值。可能的值:`accept_invalid_certs`、`strict`                                                                                                 |
| `host`                 | 否       |                        | 指向包含用於連接的 socket 的目錄                                                                                                                                     |
| `socket_timeout`       | 否       |                        | 等待單個查詢終止的最大秒數                                                                                                                                           |
| `pgbouncer`            | 否       | `false`                | 設定引擎以[啟用 PgBouncer 相容模式](/orm/prisma-client/setup-and-configuration/databases-connections/pgbouncer)                                                     |
| `statement_cache_size` | 否       | `100`                  | 自 2.1.0 起:指定每個連接快取的[預編譯語句](#prepared-statement-caching)數量                                                                                           |
| `application_name`     | 否       |                        | 自 3.3.0 起:為 application_name 設定參數指定一個值                                                                                                                  |
| `channel_binding`      | 否       | `prefer`               | 自 4.8.0 起:為 channel_binding 設定參數指定一個值                                                                                                                   |
| `options`              | 否       |                        | 自 3.8.0 起:指定在連接啟動時發送到伺服器的命令行選項                                                                                                                   |

舉例來說,如果你想連接到名為 `myschema` 的 schema,將連接池大小設定為 `5`,並為查詢設定 `3` 秒的逾時。你可以使用以下參數:

```
postgresql://USER:PASSWORD@HOST:PORT/DATABASE?schema=myschema&connection_limit=5&socket_timeout=3
```

:::tip[Prisma ORM v7 連接池]
在 Prisma ORM v7 中,[驅動程式轉接器](/orm/overview/databases/database-drivers)是關聯式資料庫的預設選項。連接池由你提供的 Node.js 驅動程式(如 `pg`)處理,而不是由 Prisma 的連接 URL 參數處理。請參閱[連接池指南](/orm/prisma-client/setup-and-configuration/databases-connections/connection-pool)以了解 v7 的預設值和設定。
:::

### 設定 SSL 連接

如果你的資料庫伺服器使用 SSL,你可以在連接 URL 中新增各種參數。以下是可能參數的概述:

- `sslmode=(disable|prefer|require)`:
  - `prefer`(預設):如果可能,優先使用 TLS,接受純文字連接。
  - `disable`:不使用 TLS。
  - `require`:需要 TLS,如果不可能則失敗。
- `sslcert=<PATH>`:伺服器憑證的路徑。這是資料庫伺服器用於簽署客戶端憑證的根憑證。如果憑證不存在於系統的受信任憑證儲存中,你需要提供此項。對於 Google Cloud,這可能是 `server-ca.pem`。憑證路徑[相對於 `./prisma` 資料夾解析](/orm/prisma-schema/overview/data-sources#securing-database-connections)
- `sslidentity=<PATH>`:從客戶端憑證和金鑰建立的 PKCS12 憑證資料庫的路徑。這是 PKCS12 格式的 SSL 身份檔案,你將使用客戶端金鑰和客戶端憑證生成它。它將這兩個檔案組合成一個檔案,並透過密碼保護它們(見下一個參數)。你可以使用以下命令(使用 `openssl`)從客戶端金鑰和客戶端憑證建立此檔案:
  ```
  openssl pkcs12 -export -out client-identity.p12 -inkey client-key.pem -in client-cert.pem
  ```
- `sslpassword=<PASSWORD>`:用於保護 PKCS12 檔案的密碼。在建立 PKCS12 檔案時,前一步中列出的 `openssl` 命令會要求輸入密碼,你需要在這裡提供完全相同的密碼。
- `sslaccept=(strict|accept_invalid_certs)`:
  - `strict`:憑證中任何缺失的值都會導致錯誤。對於 Google Cloud,特別是如果資料庫沒有網域名稱,憑證可能會缺少網域/IP 位址,在連接時會導致錯誤。
  - `accept_invalid_certs`(預設):繞過此檢查。請注意此設定的安全後果。

你的資料庫連接 URL 將類似於:

```
postgresql://USER:PASSWORD@HOST:PORT/DATABASE?sslidentity=client-identity.p12&sslpassword=mypassword&sslcert=rootca.cert
```

### 透過 socket 連接

要透過 socket 連接到 PostgreSQL 資料庫,你必須將 `host` 欄位作為_查詢參數_新增到連接 URL 中(而不是將其設定為 URI 的 `host` 部分)。
此參數的值必須指向包含 socket 的目錄,例如:`postgresql://USER:PASSWORD@localhost/database?host=/var/run/postgresql/`

請注意,`localhost` 是必需的,值本身會被忽略,可以是任何內容。

> **注意**:你可以在這個 [GitHub issue](https://github.com/prisma/prisma-client-js/issues/437#issuecomment-592436707) 中找到更多背景資訊。

## 預編譯語句快取

[預編譯語句](https://www.postgresql.org/docs/current/sql-prepare.html)是一個可用於最佳化效能的功能。預編譯語句只解析、編譯和最佳化一次,然後可以直接執行多次,而無需再次解析查詢的開銷。

透過快取預編譯語句,Prisma Client 的[查詢引擎](/orm/more/under-the-hood/engines)不會重複編譯相同的查詢,從而減少資料庫 CPU 使用率和查詢延遲。

例如,以下是 Prisma Client 執行兩個不同查詢時生成的 SQL:

```sql
SELECT * FROM user WHERE name = "John";
SELECT * FROM user WHERE name = "Brenda";
```

參數化後的兩個查詢將相同,第二個查詢可以跳過準備步驟,節省資料庫 CPU 和一次額外的資料庫往返。參數化後的查詢:

```sql
SELECT * FROM user WHERE name = $1
```

Prisma Client 維護的每個資料庫連接都有一個單獨的快取用於儲存預編譯語句。可以使用連接字串中的 `statement_cache_size` 參數調整此快取的大小。預設情況下,Prisma Client 每個連接快取 `100` 個語句。

由於 pgBouncer 的特性,如果 `pgbouncer` 參數設定為 `true`,則該連接的預編譯語句快取會自動停用。
