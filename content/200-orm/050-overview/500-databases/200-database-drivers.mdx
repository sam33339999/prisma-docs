## 預設內建驅動程式

Prisma Client 的元件之一是[查詢引擎](/orm/more/under-the-hood/engines)(使用 Rust 實作)。查詢引擎負責將 Prisma Client 查詢轉換為 SQL 語句。它使用內建驅動程式透過 TCP 連接到你的資料庫,無需額外設定。

:::note

從 Prisma ORM 7 開始,查詢編譯器(客戶端引擎)成為預設選項,這意味著 Prisma Client 生成時不包含基於 Rust 的查詢引擎二進位檔。這提供了更好的效能和開發者體驗。在[此處](/orm/prisma-client/setup-and-configuration/no-rust-engine)了解更多。

在 Prisma ORM 7 中,預設的生成器設定為:

```prisma
generator client {
  provider = "prisma-client"
  output   = "../generated/prisma"
}
```

請注意,使用查詢編譯器時需要[驅動程式轉接器](/orm/overview/databases/database-drivers#driver-adapters)。

你可以在我們的部落格上[閱讀關於此變更的效能和開發體驗改善](https://www.prisma.io/blog/prisma-orm-without-rust-latest-performance-benchmarks)。

:::

## 驅動程式轉接器

Prisma Client 可以使用 **驅動程式轉接器**透過 JavaScript 資料庫驅動程式連接並執行查詢。轉接器在 Prisma Client 和 JavaScript 資料庫驅動程式之間充當_轉譯器_。

Prisma Client 將使用查詢引擎將 Prisma Client 查詢轉換為 SQL,並透過 JavaScript 資料庫驅動程式執行生成的 SQL 查詢。

![使用 Prisma Client 和驅動程式轉接器從使用者應用程式到資料庫的查詢流程](./images/drivers/qe-query-engine-adapter.png)

有兩種不同類型的驅動程式轉接器:
- [資料庫驅動程式轉接器](#database-driver-adapters)
- [無伺服器驅動程式轉接器](#serverless-driver-adapters)

> **注意**:驅動程式轉接器可以實現使用 Prisma ORM 的應用程式的[邊緣部署](/orm/prisma-client/deployment/edge/overview)。

### 資料庫驅動程式轉接器

你可以使用資料庫驅動程式轉接器,從 Prisma Client 使用基於 Node.js 的驅動程式連接到你的資料庫。Prisma 維護以下驅動程式的轉接器:

- PostgreSQL
  - [`pg`](/orm/overview/databases/postgresql#using-the-node-postgres-driver)
- Prisma Postgres
  - [`@prisma/adapter-ppg`](/postgres/database/serverless-driver#use-with-prisma-orm)
- MySQL/MariaDB
  - [`mariadb`](/orm/overview/databases/mysql#using-the-mariadb-driver)
- SQLite
  - [`better-sqlite3`](/orm/overview/databases/sqlite#using-the-better-sqlite3-driver)
  - [`libSQL`](/orm/overview/databases/turso#how-to-connect-and-query-a-turso-database) (Turso)
- MS SQL Server
  - [`node-mssql`](/orm/overview/databases/sql-server#using-the-node-mssql-driver)

### 無伺服器驅動程式轉接器

資料庫提供商,例如 Neon 和 PlanetScale,允許你使用 TCP 以外的其他協定(例如 HTTP 和 WebSockets)連接到資料庫。這些資料庫驅動程式針對在無伺服器和邊緣環境中連接到資料庫進行了最佳化。

Prisma ORM 維護以下無伺服器驅動程式轉接器:
- [Prisma Postgres](/postgres/database/serverless-driver#use-with-prisma-orm)
- [Neon](/orm/overview/databases/neon#how-to-use-neons-serverless-driver-with-prisma-orm) (和 Vercel Postgres)
- [PlanetScale](/orm/overview/databases/planetscale#how-to-use-the-planetscale-serverless-driver-with-prisma-orm-preview)
- [Cloudflare D1](/orm/overview/databases/cloudflare-d1)

### 社群維護的資料庫驅動程式轉接器

你也可以為正在使用的資料庫建立自己的驅動程式轉接器。以下是社群維護的驅動程式轉接器清單:
- [TiDB Cloud Serverless Driver](https://github.com/tidbcloud/prisma-adapter)
- [PGlite - Postgres in WASM](https://github.com/lucasthevenet/pglite-utils/tree/main/packages/prisma-adapter)

## 使用驅動程式轉接器的注意事項

### v6.6.0 中的新驅動程式轉接器 API

在 [v6.6.0](https://github.com/prisma/prisma/releases/tag/6.6.0) 中,我們引入了一個簡化版本,用於在使用驅動程式轉接器時實例化 Prisma Client。現在你不需要建立驅動程式/客戶端的實例來傳遞給驅動程式轉接器,相反,你可以直接建立驅動程式轉接器(並在需要時向其傳遞驅動程式的選項)。

以下是使用 `@prisma/adapter-libsql` 轉接器的範例:

#### 6.6.0 之前

早期版本的 Prisma ORM 要求你先實例化驅動程式本身,然後使用該實例建立 Prisma 驅動程式轉接器。以下是使用 `@libsql/client` 驅動程式用於 LibSQL 的範例:

```typescript
import { createClient } from '@libsql/client'
import { PrismaLibSQL } from '@prisma/adapter-libsql'
import { PrismaClient } from '../prisma/generated/client'

// 使用驅動程式轉接器的舊方式(6.6.0 之前)
const driver = createClient({
  url: env.LIBSQL_DATABASE_URL,
  authToken: env.LIBSQL_DATABASE_TOKEN,
})
const adapter = new PrismaLibSQL(driver)

const prisma = new PrismaClient({ adapter })
```

#### 6.6.0 及更新版本

從 6.6.0 版本開始,你可以_直接_使用你偏好的 JS 原生驅動程式的選項來實例化驅動程式轉接器:

```typescript
import { PrismaLibSQL } from '@prisma/adapter-libsql'
import { PrismaClient } from '../generated/prisma/client'

const adapter = new PrismaLibSQL({
  url: env.LIBSQL_DATABASE_URL,
  authToken: env.LIBSQL_DATABASE_TOKEN,
})

const prisma = new PrismaClient({ adapter })
```

### 驅動程式轉接器和資料庫連接設定

在 Prisma ORM 7 中,資料庫連接 URL 在 [`prisma.config.ts`](/orm/reference/prisma-config-reference) 中設定。然而,在使用驅動程式轉接器時,連接字串需要在驅動程式轉接器初始設定時於你的_應用程式程式碼_中提供。

以下是 `pg` 驅動程式和 `@prisma/adapter-pg` 轉接器的做法:

```ts
import 'dotenv/config'
import { PrismaClient } from '../generated/prisma/client'
import { PrismaPg } from '@prisma/adapter-pg'

const adapter = new PrismaPg({ connectionString: process.env.DATABASE_URL })
const prisma = new PrismaClient({ adapter })
```

請查看你正在使用的驅動程式轉接器的文件以獲取具體的設定說明。

:::tip[調整連接池大小、逾時或其他連接參數]

請參閱[連接池指南](/orm/prisma-client/setup-and-configuration/databases-connections/connection-pool),了解 Prisma ORM v7 驅動程式轉接器的預設值以及它們如何從 Prisma ORM v6 URL 參數對應過來。

:::

:::tip[Prisma 逾時]

Prisma ORM 也有自己的可設定逾時,與資料庫驅動程式逾時是分開的。如果你看到逾時錯誤並且不確定它是來自驅動程式還是來自 Prisma Client,請參閱 [Prisma Client 逾時和交易選項文件](/orm/prisma-client/queries/transactions#transaction-options)。

:::


### 驅動程式轉接器和自訂輸出路徑

在 Prisma ORM 7 中,建議的方法是為 Prisma Client 使用自訂輸出路徑。預設輸出路徑為 `../generated/prisma`。

假設你在 Prisma schema 中將 `output` 設定為 `../generated/prisma`:

```prisma
generator client {
  provider = "prisma-client"
  output   = "../src/generated/client"
}
```

你可以從應用程式程式碼中使用相對路徑引用 Prisma Client:

```ts
import { PrismaClient } from '../generated/prisma/client'

const client = new PrismaClient()
```

或者,你可以使用連結相依性來獲得更簡潔的匯入。

<TabbedContent code>

<TabItem value="npm">

```terminal
npm add db@./generated/prisma
```

</TabItem>

<TabItem value="pnpm">

```terminal
pnpm add db@link:./generated/prisma
```

</TabItem>

<TabItem value="yarn">

```terminal
yarn add db@link:./generated/prisma
```

</TabItem>

</TabbedContent>

現在,你應該能夠使用 `db` 引用你生成的客戶端了!

```ts
import { PrismaClient } from 'db'

const client = new PrismaClient()
```

### 驅動程式轉接器和特定框架

#### Nuxt

使用驅動程式轉接器配合 [Nuxt](https://nuxt.com/) 部署到邊緣函數環境無法直接運作,但新增 `nitro.experimental.wasm` 設定選項可以解決這個問題:

```ts
export default defineNuxtConfig({
  // ...
  nitro: {
    // ...
    experimental: {
      wasm: true,
    },
  },
  // ...
})
```

### 驅動程式轉接器和 TypedSQL

[TypedSQL](/orm/prisma-client/using-raw-sql/typedsql) 讓你編寫完全型別安全的 SQL 查詢,直接與 Prisma Client 整合。如果你想要編寫 SQL 的靈活性,同時仍然受益於 Prisma 的型別安全性,這個功能非常有用。

你也可以將驅動程式轉接器與 TypedSQL 一起使用,透過 JavaScript 資料庫驅動程式進行連接。TypedSQL 適用於所有支援的驅動程式轉接器,除了 `@prisma/adapter-better-sqlite3`。如需 SQLite 支援,請改用 [`@prisma/adapter-libsql`](https://www.npmjs.com/package/@prisma/adapter-libsql)。
