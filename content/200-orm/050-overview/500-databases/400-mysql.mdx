MySQL 資料來源連接器將 Prisma ORM 連接到 [MySQL](https://www.mysql.com/) 或 [MariaDB](https://mariadb.org/) 資料庫伺服器。

預設情況下,MySQL 連接器包含負責連接到資料庫的資料庫驅動程式。你可以使用[驅動程式轉接器](/orm/overview/databases/database-drivers#driver-adapters)(預覽版)從 Prisma Client 使用 JavaScript 資料庫驅動程式連接到資料庫。

## 範例

要連接到 MySQL 資料庫伺服器,你需要在 [Prisma schema](/orm/prisma-schema) 中設定一個 [`datasource`](/orm/prisma-schema/overview/data-sources) 區塊:

```prisma file=schema.prisma showLineNumbers
datasource db {
  provider = "mysql"
}
```

`datasource` 區塊指定 `mysql` 資料來源連接器,用於 MySQL 和 MariaDB。

在 Prisma ORM 7 中,資料庫連接 URL 在 [`prisma.config.ts`](/orm/reference/prisma-config-reference) 中設定:

```typescript file=prisma.config.ts
import { defineConfig, env } from 'prisma/config'
import 'dotenv/config'

export default defineConfig({
  schema: 'prisma/schema.prisma',
  datasource: {
    url: env('DATABASE_URL'),
  },
})
```

此設定使用[環境變數](/orm/prisma-schema/overview#accessing-environment-variables-from-the-schema)來提供資料庫連接 URL。

## 使用 `mariadb` 驅動程式

從 [`v5.4.0`](https://github.com/prisma/prisma/releases/tag/5.4.0) 開始,你可以使用 Prisma ORM 配合 JavaScript 生態系統中的資料庫驅動程式(而不是使用 Prisma ORM 的內建驅動程式)。你可以透過使用[驅動程式轉接器](/orm/overview/databases/database-drivers)來實現這一點。

對於 MySQL 和 MariaDB,[`mariadb`](https://github.com/mariadb-corporation/mariadb-connector-nodejs) 是 JavaScript 生態系統中最受歡迎的驅動程式之一。

本節說明如何與 Prisma ORM 和 `@prisma/adapter-mariadb` 驅動程式轉接器一起使用。

### 1. 安裝相依性

首先,安裝 Prisma ORM 的 `mariadb` 驅動程式轉接器:

```terminal
npm install @prisma/adapter-mariadb
```

### 2. 使用驅動程式轉接器實例化 Prisma Client

現在,當你實例化 Prisma Client 時,需要將 Prisma ORM 的驅動程式轉接器實例傳遞給 `PrismaClient` 建構函式:

```ts
import 'dotenv/config'
import { PrismaMariaDb } from '@prisma/adapter-mariadb'
import { PrismaClient } from '../generated/prisma/client'

const adapter = new PrismaMariaDb({
  host: "localhost",
  port: 3306,
  connectionLimit: 5
})
const prisma = new PrismaClient({ adapter })
```

## 連接詳情

### 連接 URL

以下是 MySQL 連接 URL 所需元件的概述:

![MySQL 連接 URL 的結構](./mysql-connection-string.png)

#### 基礎 URL 和路徑

以下是使用大寫字母佔位符值的_基礎 URL_ 和_路徑_結構範例:

```
mysql://USER:PASSWORD@HOST:PORT/DATABASE
```

以下元件組成了資料庫的_基礎 URL_,它們始終是必需的:

| 名稱     | 佔位符      | 描述                                                                                                                |
| :------- | :---------- | :----------------------------------------------------------------------------------------------------------------- |
| Host     | `HOST`      | 資料庫伺服器的 IP 位址/網域,例如 `localhost`                                                                          |
| Port     | `PORT`      | 資料庫伺服器運行的埠號,例如 `5432` (預設為 `3306`,或使用 Unix socket 時無埠號)                                         |
| User     | `USER`      | 資料庫使用者的名稱,例如 `janedoe`                                                                                     |
| Password | `PASSWORD`  | 資料庫使用者的密碼                                                                                                    |
| Database | `DATABASE`  | 你想使用的[資料庫](https://dev.mysql.com/doc/refman/8.0/en/creating-database.html)名稱,例如 `mydb`                   |

:::info

你必須對[特殊字元進行百分比編碼](/orm/reference/connection-urls#special-characters)。

:::

#### 參數

連接 URL 也可以接受參數。以下是使用大寫字母佔位符值表示三個_參數_的相同範例:

```
mysql://USER:PASSWORD@HOST:PORT/DATABASE?KEY1=VALUE&KEY2=VALUE&KEY3=VALUE
```

可以使用以下參數:

| 參數名稱            | 必需     | 預設值                  | 描述                                                                                                                                                                |
| :----------------- | :------- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `connection_limit` | 否       | `num_cpus * 2 + 1`     | [連接池](/orm/prisma-client/setup-and-configuration/databases-connections/connection-pool)的最大大小(Prisma ORM v6 及更早版本)                                    |
| `connect_timeout`  | 否       | `5`                    | 等待新連接開啟的最大秒數,`0` 表示無逾時                                                                                                                               |
| `pool_timeout`     | 否       | `10`                   | 等待從連接池獲取新連接的最大秒數,`0` 表示無逾時                                                                                                                        |
| `sslcert`          | 否       |                        | 伺服器憑證的路徑。憑證路徑[相對於 `./prisma` 資料夾解析](/orm/prisma-schema/overview/data-sources#securing-database-connections)                                     |
| `sslidentity`      | 否       |                        | PKCS12 憑證的路徑                                                                                                                                                   |
| `sslpassword`      | 否       |                        | 用於保護 PKCS12 檔案的密碼                                                                                                                                          |
| `sslaccept`        | 否       | `accept_invalid_certs` | 設定是否檢查憑證中缺失的值。可能的值:`accept_invalid_certs`、`strict`                                                                                                 |
| `socket`           | 否       |                        | 指向包含用於連接的 socket 的目錄                                                                                                                                     |
| `socket_timeout`   | 否       |                        | 等待單個查詢終止的秒數                                                                                                                                               |

舉例來說,如果你想將連接池大小設定為 `5`,並為查詢設定 `3` 秒的逾時,你可以使用以下參數:

```
mysql://USER:PASSWORD@HOST:PORT/DATABASE?connection_limit=5&socket_timeout=3
```

:::tip[Prisma ORM v7 連接池]
在 Prisma ORM v7 中,[驅動程式轉接器](/orm/overview/databases/database-drivers)是關聯式資料庫的預設選項。連接池由你提供的 Node.js 驅動程式(如 `mariadb`)處理,而不是由 Prisma 的連接 URL 參數處理。請參閱[連接池指南](/orm/prisma-client/setup-and-configuration/databases-connections/connection-pool)以了解 v7 的預設值和設定。
:::

### 設定 SSL 連接

如果你的資料庫伺服器使用 SSL,你可以在連接 URL 中新增各種參數。以下是可能參數的概述:

- `sslcert=<PATH>`:伺服器憑證的路徑。這是資料庫伺服器用於簽署客戶端憑證的根憑證。如果憑證不存在於系統的受信任憑證儲存中,你需要提供此項。對於 Google Cloud,這可能是 `server-ca.pem`。憑證路徑[相對於 `./prisma` 資料夾解析](/orm/prisma-schema/overview/data-sources#securing-database-connections)

- `sslidentity=<PATH>`:從客戶端憑證和金鑰建立的 PKCS12 憑證資料庫的路徑。這是 PKCS12 格式的 SSL 身份檔案,你將使用客戶端金鑰和客戶端憑證生成它。它將這兩個檔案組合成一個檔案,並透過密碼保護它們(見下一個參數)。你可以使用以下命令(使用 `openssl`)從客戶端金鑰和客戶端憑證建立此檔案:
  ```
  openssl pkcs12 -export -out client-identity.p12 -inkey client-key.pem -in client-cert.pem
  ```
- `sslpassword=<PASSWORD>`:用於保護 PKCS12 檔案的密碼。在建立 PKCS12 檔案時,前一步中列出的 `openssl` 命令會要求輸入密碼,你需要在這裡提供完全相同的密碼。
- `sslaccept=(strict|accept_invalid_certs)`:
  - `strict`:憑證中任何缺失的值都會導致錯誤。對於 Google Cloud,特別是如果資料庫沒有網域名稱,憑證可能會缺少網域/IP 位址,在連接時會導致錯誤。
  - `accept_invalid_certs`(預設):繞過此檢查。請注意此設定的安全後果。

你的資料庫連接 URL 將類似於:

```
mysql://USER:PASSWORD@HOST:PORT/DATABASE?sslidentity=client-identity.p12&sslpassword=mypassword&sslcert=rootca.cert
```

### 透過 socket 連接

要透過 socket 連接到 MySQL/MariaDB 資料庫,你必須將 `socket` 欄位作為_查詢參數_新增到連接 URL 中(而不是將其設定為 URI 的 `host` 部分)。
此參數的值必須指向包含 socket 的目錄,例如在 Ubuntu 或 Debian 上的 MySQL/MariaDB 預設安裝使用:`mysql://USER:PASSWORD@HOST/DATABASE?socket=/run/mysqld/mysqld.sock`

請注意,`localhost` 是必需的,值本身會被忽略,可以是任何內容。

> **注意**:你可以在這個 [GitHub issue](https://github.com/prisma/prisma-client-js/issues/437#issuecomment-592436707) 中找到更多背景資訊。

### 從 Prisma ORM 到 MySQL 的原生型別映射

## 引擎

如果你使用的 MySQL 版本中 MyISAM 是預設引擎,你在建立表格時必須指定 `ENGINE = InnoDB;`。如果你內省使用不同引擎的資料庫,Prisma Schema 中的關聯將不會被建立(或如果關聯已存在則會遺失)。

## 權限

全新安裝的 MySQL/MariaDB 預設只有一個 `root` 資料庫使用者。請不要在 Prisma 設定中使用 `root` 使用者,而是為每個應用程式建立資料庫和資料庫使用者。在大多數 Linux 主機(例如 Ubuntu)上,你可以簡單地以 Linux `root` 使用者身分執行此操作(它自動也具有資料庫 `root` 存取權限):

```
mysql -e "CREATE DATABASE IF NOT EXISTS $DB_PRISMA;"
mysql -e "GRANT ALL PRIVILEGES ON $DB_PRISMA.* TO $DB_USER@'%' IDENTIFIED BY '$DB_PASSWORD';"
```

以上足以執行 `prisma db pull` 和 `prisma db push` 命令。為了也能執行 `prisma migrate` 命令,需要授予這些權限:

```
mysql -e "GRANT CREATE, DROP, REFERENCES, ALTER ON *.* TO $DB_USER@'%';"
```
