:::info 快速摘要
學習如何在 Windows 上本地設定和配置 Microsoft SQL Server 以與 Prisma ORM 一起使用。
:::


<TopBlock>

要在 Windows 電腦上本地執行 Microsoft SQL Server:

1. 如果您沒有 Microsoft SQL Server 實例的存取權限,請下載並設定 [SQL Server 2019 Developer](https://www.microsoft.com/en-us/sql-server/sql-server-downloads)。

1. 下載並安裝 [SQL Server Management Studio](https://learn.microsoft.com/en-us/sql/ssms/download-sql-server-management-studio-ssms?view=sql-server-ver15)。

1. 使用 Windows 身份驗證登入到 Microsoft SQL Server Management Studio(展開 **Server Name** 下拉選單並點選 **&lt;Browse for more...&gt;** 以尋找您的資料庫引擎):

![The New Query button in SQL Server Management Studio](/img/orm/connect-sql-server.png)

</TopBlock>

## 啟用 TCP/IP

Prisma Client 需要啟用 TCP/IP。要啟用 TCP/IP:

1. 開啟 SQL Server Configuration Manager。(在開始選單中搜尋「SQL Server Configuration Manager」,或開啟開始選單並輸入「SQL Server Configuration Manager」。)

1. 在左側面板中,點選 **SQL Server Network Configuration** > **Protocols for MSSQLSERVER**

1. 右鍵點選 **TCP/IP** 並選擇 **Enable**。

## 啟用 SQL 登入的身份驗證(選擇性)

如果您想在連接 URL 中使用使用者名稱和密碼而不是整合安全性,[啟用混合身份驗證模式](https://learn.microsoft.com/en-us/sql/database-engine/configure-windows/change-server-authentication-mode?view=sql-server-ver15&tabs=ssms),步驟如下:

1. 在物件總管中右鍵點選您的資料庫引擎並點選 **Properties**。

1. 在 Server Properties 視窗中,在左側清單中點選 **Security** 並勾選 **SQL Server and Windows Authentication Mode** 選項,然後點選 **OK**。

1. 在物件總管中右鍵點選您的資料庫引擎並點選 **Restart**。

### 啟用 `sa` 登入

要啟用預設的 `sa`(管理員)SQL Server 登入:

1. 在 SQL Server Management Studio 的物件總管中,展開 **Security** > **Logins** 並雙擊 **sa**。

1. 在 **General** 頁面上,為 `sa` 帳戶選擇密碼(如果您不想強制執行原則,請取消勾選 **Enforce password policy**)。

1. 在 **Status** 頁面上,在 **Settings** > **Login** 下,勾選 **Enabled**,然後點選 **OK**。

您現在可以在連接 URL 中和登入 SQL Server Management Studio 時使用 `sa` 帳戶。

> **注意**: `sa` 使用者具有廣泛的權限。您也可以[建立具有較少權限的自己的登入](https://learn.microsoft.com/en-us/sql/relational-databases/security/authentication-access/create-a-login?view=sql-server-ver15)。
