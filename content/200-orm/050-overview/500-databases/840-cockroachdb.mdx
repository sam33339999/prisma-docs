本指南探討使用 Prisma ORM 和 CockroachDB 的相關概念,說明 CockroachDB 與其他資料庫提供者之間的共通性和差異,並引導您完成配置應用程式以整合 CockroachDB 的過程。

:::info

CockroachDB 連接器在 `3.14.0` 及更高版本中正式可用。它首次作為[預覽功能](/orm/reference/preview-features)添加於版本 [`3.9.0`](https://github.com/prisma/prisma/releases/tag/3.9.0),支援 Introspection,而 Prisma Migrate 支援則在 [`3.11.0`](https://github.com/prisma/prisma/releases/tag/3.11.0) 中添加。

:::

## 什麼是 CockroachDB?

CockroachDB 是一個為可擴展性和高可用性設計的分散式資料庫。功能包括:

- **與 PostgreSQL 相容:** CockroachDB 與 PostgreSQL 相容,允許與大量現有產品生態系統互通
- **內建擴展:** CockroachDB 具備自動複製、故障轉移和修復功能,可輕鬆進行應用程式的水平擴展

## 與其他資料庫提供者的共通性

CockroachDB 與 PostgreSQL 高度相容,大部分情況下可以用與 Prisma ORM 相同的方式使用。您仍然可以:

- 使用 [Prisma Schema Language](/orm/prisma-schema) 建模您的資料庫
- 使用 Prisma ORM 的 [`cockroachdb` 資料庫連接器](/orm/overview/databases/cockroachdb)連接到您的資料庫
- 如果您已有 CockroachDB 資料庫,可在現有專案中使用 [Introspection](/orm/prisma-schema/introspection)
- 使用 [Prisma Migrate](/orm/prisma-migrate) 將資料庫架構遷移到新版本
- 在應用程式中使用 [Prisma Client](/orm/prisma-client),根據您的 Prisma Schema 以類型安全的方式查詢資料庫

## 需要考慮的差異

在使用 Prisma ORM 的 `cockroachdb` 連接器時,需要注意一些 CockroachDB 特定的差異:

- **Cockroach 特定的原生類型:** Prisma ORM 的 `cockroachdb` 資料庫連接器提供對 CockroachDB 原生資料類型的支援。要了解更多,請參閱 [如何使用 CockroachDB 的原生類型](#how-to-use-cockroachdbs-native-types)。

- **建立資料庫鍵:** Prisma ORM 允許您使用 [`autoincrement()`](/orm/reference/prisma-schema-reference#autoincrement) 函式為每筆記錄生成唯一識別碼。更多資訊請參閱 [如何在 CockroachDB 中使用資料庫鍵](#how-to-use-database-keys-with-cockroachdb)。

## 如何在 CockroachDB 中使用 Prisma ORM

本節提供如何使用 CockroachDB 特定功能的更多詳細資訊。

### 如何使用 CockroachDB 的原生類型

CockroachDB 有自己的一套原生[資料類型](https://www.cockroachlabs.com/docs/stable/data-types.html),這些類型在 Prisma ORM 中受支援。例如,CockroachDB 使用 `STRING` 資料類型,而不是 PostgreSQL 的 `VARCHAR`。

作為示範,假設您使用以下 SQL 命令在 CockroachDB 資料庫中建立 `User` 表:

```sql
CREATE TABLE public."Post" (
  "id" INT8 NOT NULL,
  "title" VARCHAR(200) NOT NULL,
  CONSTRAINT "Post_pkey" PRIMARY KEY ("id" ASC),
  FAMILY "primary" ("id", "title")
);
```

使用 `npx prisma db pull` 內省資料庫後,您的 Prisma Schema 中將會有一個新的 `Post` 模型:

```prisma file=schema.prisma showLineNumbers
model Post {
  id    BigInt @id
  title String @db.String(200)
}
```

請注意,`title` 欄位已被標註為 `@db.String(200)` — 這與 PostgreSQL 不同,在 PostgreSQL 中標註會是 `@db.VarChar(200)`。

有關類型對應的完整列表,請參閱我們的[連接器文件](/orm/overview/databases/cockroachdb#type-mapping-between-cockroachdb-and-the-prisma-schema)。

### 如何在 CockroachDB 中使用資料庫鍵

在像 CockroachDB 這樣的分散式資料庫中為記錄生成唯一識別碼時,最好避免使用連續 ID — 有關此主題的更多資訊,請參閱 CockroachDB 關於[選擇索引鍵的部落格文章](https://www.cockroachlabs.com/blog/how-to-choose-db-index-keys/)。

相反,Prisma ORM 提供 [`autoincrement()`](/orm/reference/prisma-schema-reference#autoincrement) 屬性函式,它使用 CockroachDB 的 [`unique_rowid()` 函式](https://www.cockroachlabs.com/docs/stable/serial.html)來生成唯一識別碼。例如,以下 `User` 模型具有使用 `autoincrement()` 函式生成的 `id` 主鍵:

```prisma file=schema.prisma showLineNumbers
model User {
  id   BigInt @id @default(autoincrement())
  name String
}
```

為了與現有資料庫相容,有時您仍然需要生成固定序列的整數鍵值。在這些情況下,您可以使用 Prisma ORM 為 CockroachDB 內建的 [`sequence()`](/orm/reference/prisma-schema-reference#sequence) 函式。有關 `sequence()` 函式可用選項的列表,請參閱我們的[參考文件](/orm/reference/prisma-schema-reference#sequence)。

有關生成資料庫鍵的更多資訊,請參閱 CockroachDB 的[主鍵最佳實踐](https://www.cockroachlabs.com/docs/v21.2/schema-design-table#primary-key-best-practices)指南。

## 範例

要連接到 CockroachDB 資料庫伺服器,您需要在 [Prisma schema](/orm/prisma-schema) 中配置一個 [`datasource`](/orm/prisma-schema/overview/data-sources) 區塊:

```prisma file=schema.prisma showLineNumbers
datasource db {
  provider = "cockroachdb"
}
```

資料庫連接 URL 在 `prisma.config.ts` 中配置:

```ts file=prisma.config.ts
import 'dotenv/config'
import { defineConfig, env } from 'prisma/config'

export default defineConfig({
  schema: 'prisma/schema.prisma',
  datasource: {
    url: env('DATABASE_URL'),
  },
})
```

:::info

使用 Prisma CLI 命令時,環境變數不會自動載入。您需要使用像 `dotenv` 這樣的套件從 `.env` 檔案載入環境變數,或確保在您的 shell 中設定環境變數。

:::

傳遞給 `datasource` 區塊的欄位有:

- `provider`: 指定 `cockroachdb` 資料來源連接器。
- `url` 欄位在 `prisma.config.ts` 中配置,並指定 CockroachDB 資料庫伺服器的[連接 URL](#connection-details)。

:::info

雖然 `cockroachdb` 和 `postgresql` 連接器相似,但從版本 5.0.0 開始連接 CockroachDB 資料庫時,必須使用 `cockroachdb` 連接器而不是 `postgresql`。

:::

## 連接詳細資訊

CockroachDB 的連接 URL 使用 PostgreSQL 格式。有關此格式的詳細資訊以及它接受的可選參數,請參閱 [PostgreSQL 連接器文件](/orm/overview/databases/postgresql#connection-details)。

## CockroachDB 與 PostgreSQL 的差異

下表列出了 CockroachDB 與 PostgreSQL 之間的差異:

| 問題                                                                                                                                                                                                                                                                           | 區域   | 備註                                                                                                                                                                                      |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 預設情況下,在 CockroachDB 中 `INT` 類型是 `INT8` 的別名,而在 PostgreSQL 中它是 `INT4` 的別名。這意味著 Prisma ORM 在 CockroachDB 中會將 `INT` 欄位內省為 `BigInt`,而在 PostgreSQL 中 Prisma ORM 會將其內省為 `Int`。         | Schema | 有關 `INT` 類型的更多資訊,請參閱 [CockroachDB 文件](https://www.cockroachlabs.com/docs/stable/int.html#considerations-for-64-bit-signed-integers)                  |
| 在欄位上使用 `@default(autoincrement())` 時,CockroachDB 會自動為行 ID 生成 64 位元整數。這些整數是遞增的但不是連續的。這與 PostgreSQL 不同,在 PostgreSQL 中生成的行 ID 是連續的且從 1 開始。 | Schema | 有關生成值的更多資訊,請參閱 [CockroachDB 文件](https://www.cockroachlabs.com/docs/stable/serial.html#generated-values-for-modes-rowid-and-virtual_sequence) |
| `@default(autoincrement())` 屬性只能與 `BigInt` 欄位類型一起使用。                                                                                                                                                                               | Schema | 有關生成值的更多資訊,請參閱 [CockroachDB 文件](https://www.cockroachlabs.com/docs/stable/serial.html#generated-values-for-modes-rowid-and-virtual_sequence) |

## CockroachDB 的類型對應限制

CockroachDB 連接器將 Prisma ORM [資料模型](/orm/prisma-schema/data-model/models)中的[純量類型](/orm/prisma-schema/data-model/models#scalar-fields)對應到原生欄位類型。這些原生類型大部分與 PostgreSQL 相同 — 詳情請參閱 [從 Prisma ORM 到 CockroachDB 的原生類型對應](#native-type-mapping-from-prisma-orm-to-cockroachdb)。然而,有一些限制:

| CockroachDB (類型 \| 別名) | Prisma ORM | 支援 | 原生資料庫類型屬性 | 備註                                                                                                                      |
| ----------------------------- | ---------- | :-------: | :----------------------------- | :------------------------------------------------------------------------------------------------------------------------- |
| `money`                       | `Decimal`  |  尚未支援  | `@db.Money`                    | PostgreSQL 支援,但 [CockroachDB 目前不支援](https://github.com/cockroachdb/cockroach/issues/41578)          |
| `xml`                         | `String`   |  尚未支援  | `@db.Xml`                      | PostgreSQL 支援,但 [CockroachDB 目前不支援](https://github.com/cockroachdb/cockroach/issues/43355)          |
| `jsonb` 陣列                | `Json[]`   |  尚未支援  | N/A                            | PostgreSQL 支援 `Json[]`,但 [CockroachDB 目前不支援](https://github.com/cockroachdb/cockroach/issues/23468) |

## 其他限制

下表列出了 CockroachDB 與 PostgreSQL 相比目前已知的其他限制:

| 問題                                                                                                | 區域          | 備註                                                                                                                                                                                                                                                           |
| ---------------------------------------------------------------------------------------------------- | ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 不支援 `Hash`、`Gist`、`SpGist` 或 `Brin` 索引類型。                                    | Schema        | 在 PostgreSQL 中,Prisma ORM 允許[配置索引](/orm/prisma-schema/data-model/indexes#configuring-the-access-type-of-indexes-with-type-postgresql)以使用不同的索引存取方法。CockroachDB 目前僅支援 `BTree` 和 `Gin`。 |
| 不支援對 `Enum` 類型的推送                                                                | Client        | 對 `Enum` 類型的推送(例如 `data: { enum { push: "A" }, }`)目前 [CockroachDB 不支援](https://github.com/cockroachdb/cockroach/issues/71388)                                                                                               |
| 不支援在沒有全文索引的 `String` 欄位上搜尋                                 | Client        | 在沒有全文索引的 `String` 欄位上搜尋(例如 `where: { text: { search: "cat & dog", }, },`)目前 [CockroachDB 不支援](https://github.com/cockroachdb/cockroach/issues/7821)                                                   |
| 不支援整數除法                                                                       | Client        | 整數除法(例如 `data: { int: { divide: 10, }, }`)目前 [CockroachDB 不支援](https://github.com/cockroachdb/cockroach/issues/41448)                                                                                                    |
| 對 `Json` 欄位的過濾有限                                                                   | Client        | 目前 CockroachDB [僅支援](https://github.com/cockroachdb/cockroach/issues/49144)對 `Json` 欄位的 `equals` 和 `not` 過濾                                                                                                                      |

## CockroachDB 與 Prisma schema 之間的類型對應

CockroachDB 連接器將 Prisma ORM [資料模型](/orm/prisma-schema/data-model/models)中的[純量類型](/orm/prisma-schema/data-model/models#scalar-fields)對應到原生欄位類型如下:

> 或者,查看 [Prisma schema 參考文件](/orm/reference/prisma-schema-reference#model-field-scalar-types)以了解按 Prisma ORM 類型組織的類型對應。

### 從 Prisma ORM 到 CockroachDB 的原生類型對應

| Prisma ORM | CockroachDB      |
| ---------- | ---------------- |
| `String`   | `STRING`         |
| `Boolean`  | `BOOL`           |
| `Int`      | `INT4`           |
| `BigInt`   | `INT8`           |
| `Float`    | `FLOAT8`         |
| `Decimal`  | `DECIMAL(65,30)` |
| `DateTime` | `TIMESTAMP(3)`   |
| `Json`     | `JSONB`          |
| `Bytes`    | `BYTES`          |

### 內省時從 CockroachDB 到 Prisma ORM 類型的對應

內省 CockroachDB 資料庫時,資料庫類型會根據下表對應到 Prisma ORM:

| CockroachDB (類型 \| 別名)                | Prisma ORM | 支援 | 原生資料庫類型屬性 | 備註                                                                  |
| -------------------------------------------- | ---------- | :-------: | :----------------------------- | :--------------------------------------------------------------------- |
| `INT` \| `BIGINT`, `INTEGER`                 | `BigInt`   |    ✔️     | `@db.Int8`                     |                                                                        |
| `BOOL` \| `BOOLEAN`                          | `Bool`     |    ✔️     | `@db.Bool`\*                   |                                                                        |
| `TIMESTAMP` \| `TIMESTAMP WITHOUT TIME ZONE` | `DateTime` |    ✔️     | `@db.Timestamp(x)`             |                                                                        |
| `TIMESTAMPTZ` \| `TIMESTAMP WITH TIME ZONE`  | `DateTime` |    ✔️     | `@db.Timestamptz(x)`           |                                                                        |
| `TIME` \| `TIME WITHOUT TIME ZONE`           | `DateTime` |    ✔️     | `@db.Time(x)`                  |                                                                        |
| `TIMETZ` \| `TIME WITH TIME ZONE`            | `DateTime` |    ✔️     | `@db.Timetz(x)`                |                                                                        |
| `DECIMAL(p,s)` \| `NUMERIC(p,s)`, `DEC(p,s)` | `Decimal`  |    ✔️     | `@db.Decimal(x, y)`            |                                                                        |
| `REAL` \| `FLOAT4`, `FLOAT`                  | `Float`    |    ✔️     | `@db.Float4`                   |                                                                        |
| `DOUBLE PRECISION` \| `FLOAT8`               | `Float`    |    ✔️     | `@db.Float8`                   |                                                                        |
| `INT2` \| `SMALLINT`                         | `Int`      |    ✔️     | `@db.Int2`                     |                                                                        |
| `INT4`                                       | `Int`      |    ✔️     | `@db.Int4`                     |                                                                        |
| `CHAR(n)` \| `CHARACTER(n)`                  | `String`   |    ✔️     | `@db.Char(x)`                  |                                                                        |
| `"char"`                                     | `String`   |    ✔️     | `@db.CatalogSingleChar`        | CockroachDB 目錄表的內部類型,不適合終端使用者使用。 |
| `STRING` \| `TEXT`, `VARCHAR`                | `String`   |    ✔️     | `@db.String`                   |                                                                        |
| `DATE`                                       | `DateTime` |    ✔️     | `@db.Date`                     |                                                                        |
| `ENUM`                                       | `enum`     |    ✔️     | N/A                            |                                                                        |
| `INET`                                       | `String`   |    ✔️     | `@db.Inet`                     |                                                                        |
| `BIT(n)`                                     | `String`   |    ✔️     | `@Bit(x)`                      |                                                                        |
| `VARBIT(n)` \| `BIT VARYING(n)`              | `String`   |    ✔️     | `@VarBit`                      |                                                                        |
| `OID`                                        | `Int`      |    ✔️     | `@db.Oid`                      |                                                                        |
| `UUID`                                       | `String`   |    ✔️     | `@db.Uuid`                     |                                                                        |
| `JSONB` \| `JSON`                            | `Json`     |    ✔️     | `@db.JsonB`                    |                                                                        |
| 陣列類型                                  | `[]`       |    ✔️     |                                |                                                                        |

[Introspection](/orm/prisma-schema/introspection) 會將**尚未支援**的原生資料庫類型添加為 [`Unsupported`](/orm/reference/prisma-schema-reference#unsupported) 欄位:

```prisma file=schema.prisma showLineNumbers
model Device {
  id       BigInt                  @id @default(autoincrement())
  interval Unsupported("INTERVAL")
}
```
