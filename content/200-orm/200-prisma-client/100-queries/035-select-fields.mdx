## 概述

預設情況下,當查詢返回記錄時(而不是計數),結果包括:

- 模型的**所有純量欄位**(包括列舉)
- 模型上定義的**無關聯**

例如,考慮以下 schema:

```prisma
model User {
  id        Int      @id @default(autoincrement())
  email     String   @unique
  name      String?
  role      Role     @default(USER)
  posts     Post[]
}

model Post {
  id        Int      @id @default(autoincrement())
  published Boolean  @default(false)
  title     String  
  author    User?    @relation(fields: [authorId], references: [id])
  authorId  Int?
}

enum Role {
  USER
  ADMIN
}
```

對 `User` 模型的查詢將包含 `id`、`email`、`name` 和 `role` 欄位(因為這些是_純量_欄位),但不包含 `posts` 欄位(因為那是_關聯_欄位):

<CodeWithResult expanded="{true}" outputResultText="query">
<cmd>

```ts
const users = await prisma.user.findFirst()
```

</cmd>
<cmdResult>

```js no-copy
{
  id: 42,
  name: "Sabelle",
  email: "sabelle@prisma.io",
  role: "ADMIN"
}
```

</cmdResult>
</CodeWithResult>

如果您想自訂結果並返回不同的欄位組合,您可以:

- 使用 [`select`](/orm/reference/prisma-client-reference#select) 返回特定欄位。您也可以透過選擇關聯欄位來使用[巢狀 `select`](/orm/prisma-client/queries/relation-queries#select-specific-fields-of-included-relations)。
- 使用 [`omit`](/orm/reference/prisma-client-reference#omit) 從結果中排除特定欄位。`omit` 可以看作是 `select` 的"相反"。
- 使用 [`include`](/orm/reference/prisma-client-reference#include) 額外[包含關聯](/orm/prisma-client/queries/relation-queries#nested-reads)。

在所有情況下,查詢結果都將是靜態類型的,確保您不會意外存取任何實際上沒有從資料庫查詢的欄位。

僅選擇您需要的欄位和關聯,而不是依賴預設選擇集,可以減少回應的大小並提高查詢速度。

從版本 [5.9.0](https://github.com/prisma/prisma/releases/tag/5.9.0) 開始,當使用 `include` 或在關聯欄位上使用 `select` 進行關聯查詢時,您還可以指定 `relationLoadStrategy` 來決定是要使用資料庫層級的 join 還是執行多個查詢並在應用程式層級合併資料。此功能目前處於[預覽](/orm/more/releases#preview)狀態,您可以在[這裡](/orm/prisma-client/queries/relation-queries#relation-load-strategies-preview)了解更多資訊。

## 範例 schema

本頁面的所有後續範例都基於以下 schema:

```prisma
model User {
  id           Int       @id 
  name         String?
  email        String    @unique
  password     String
  role         Role      @default(USER)
  coinflips    Boolean[]
  posts        Post[]
  profile      Profile?
}

model Post {
  id        Int     @id 
  title     String
  published Boolean @default(true)
  author    User    @relation(fields: [authorId], references: [id])
  authorId  Int
}

model Profile {
  id        Int    @id 
  biography String
  user      User   @relation(fields: [userId], references: [id])
  userId    Int    @unique
}

enum Role {
  USER
  ADMIN
}
```


## 返回預設欄位

以下查詢返回預設欄位(所有純量欄位,無關聯):

<CodeWithResult expanded="{true}" outputResultText="query">
<cmd>

```ts
const user = await prisma.user.findFirst()
```

</cmd>
<cmdResult>

```js no-copy
{
  id: 22,
  name: "Alice",
  email: "alice@prisma.io",
  password: "mySecretPassword42"
  role: "ADMIN",
  coinflips: [true, false],
}
```

</cmdResult>
</CodeWithResult>

## 選擇特定欄位

使用 `select` 返回欄位的_子集_而不是_所有_欄位。以下範例僅返回 `email` 和 `name` 欄位:

<CodeWithResult expanded="{true}" outputResultText="query">
<cmd>

```ts
const user = await prisma.user.findFirst({
  select: {
    email: true,
    name: true,
  },
})
```

</cmd>
<cmdResult>

```js no-copy
{
  name: "Alice",
  email: "alice@prisma.io",
}
```

</cmdResult>
</CodeWithResult>

## 透過選擇關聯欄位返回巢狀物件

您也可以透過在[關聯欄位](/orm/prisma-schema/data-model/relations#relation-fields)上多次巢狀 `select` 來返回關聯。

以下查詢使用巢狀 `select` 選擇每個使用者的 `name` 和每篇相關貼文的 `title`:

<CodeWithResult expanded="{true}" outputResultText="query">
<cmd>

```ts highlight=normal;2,5
const usersWithPostTitles = await prisma.user.findFirst({
  select: {
    name: true,
    posts: {
      select: { title: true },
    },
  },
})
```

</cmd>
<cmdResult>

```js no-copy
{
  "name":"Sabelle",
  "posts":[
    { "title":"Getting started with Azure Functions" },
    { "title":"All about databases" }
  ]
}
```

</cmdResult>
</CodeWithResult>

以下查詢在 `include` 中使用 `select`,並返回_所有_使用者欄位和每篇貼文的 `title` 欄位:

<CodeWithResult expanded="{true}" outputResultText="query">
<cmd>

```ts highlight=normal;2,5
const usersWithPostTitles = await prisma.user.findFirst({
  include: {
    posts: {
      select: { title: true },
    },
  },
})
```

</cmd>
<cmdResult>

```js no-copy
{
  id: 9
  name: "Sabelle",
  email: "sabelle@prisma.io",
  password: "mySecretPassword42",
  role: "USER",
  coinflips: [],
  posts:[
    { title:"Getting started with Azure Functions" },
    { title:"All about databases" }
  ]
}
```

</cmdResult>
</CodeWithResult>

您可以任意深度巢狀查詢。以下查詢獲取:
- `Post` 的 `title`
- 相關 `User` 的 `name`
- 相關 `Profile` 的 `biography`

<CodeWithResult expanded="{true}" outputResultText="query">
<cmd>

```ts highlight=normal;2,5
const postsWithAuthorsAndProfiles = await prisma.post.findFirst({
  select: {
    title: true,
    author: {
      select: { 
        name: true,
        profile: {
          select: { biography: true }
        }
      },
    },
  },
})
```

</cmd>
<cmdResult>

```js no-copy
{
  id: 9
  title:"All about databases",
  author: {
    name: "Sabelle",.
    profile: {
      biography: "I like turtles"
    }
  }
}
```

</cmdResult>
</CodeWithResult>

:::note

當深度巢狀關聯時請小心,因為底層資料庫查詢可能會因為需要存取許多不同的資料表而變慢。為確保您的查詢始終具有最佳速度,請考慮使用 [Prisma Accelerate](/accelerate) 新增快取層,或使用 [Prisma Optimize](/optimize/) 取得查詢洞察和效能最佳化建議。

:::

有關查詢關聯的更多資訊,請參閱以下文件:

- [包含關聯(包括所有欄位)](/orm/prisma-client/queries/relation-queries#include-all-fields-for-a-specific-relation)
- [選擇特定關聯欄位](/orm/prisma-client/queries/relation-queries#select-specific-fields-of-included-relations)

## 省略特定欄位

在某些情況下,您可能想要返回模型的_大部分_欄位,僅排除_一小部分_。一個常見的例子是當您查詢 `User` 但出於安全原因想要排除 `password` 欄位時。

在這些情況下,您可以使用 `omit`,它可以看作是 `select` 的對應物:

<CodeWithResult expanded="{true}" outputResultText="query">
<cmd>

```ts
const users = await prisma.user.findFirst({
  omit: {
    password: true
  }
})
```

</cmd>
<cmdResult>

```js no-copy
{
  id: 9
  name: "Sabelle",
  email: "sabelle@prisma.io",
  profileViews: 90,
  role: "USER",
  coinflips: [],
}
```

</cmdResult>
</CodeWithResult>

請注意,返回的物件_不_包含 `password` 欄位。

## 關聯計數

在 [3.0.1](https://github.com/prisma/prisma/releases/3.0.1) 及更高版本中,您可以在欄位旁邊 `include` 或 `select` [關聯的計數](/orm/prisma-client/queries/aggregation-grouping-summarizing#count-relations)。例如,使用者的貼文數量。
