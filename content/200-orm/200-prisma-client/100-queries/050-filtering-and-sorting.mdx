Prisma Client 支援使用 `where` 查詢選項進行[篩選](#filtering),以及使用 `orderBy` 查詢選項進行[排序](#sorting)。

## 篩選

Prisma Client 允許您根據模型欄位的任何組合(包括[相關模型](#filter-on-relations))來篩選記錄,並支援多種[篩選條件](#filter-conditions-and-operators)。

:::warning

某些篩選條件使用 SQL 運算子 `LIKE` 和 `ILIKE`,這可能會在您的查詢中造成意外行為。請參閱[我們的篩選常見問題](#filtering-faqs)了解更多資訊。

:::

以下查詢:

- 返回所有 `User` 記錄,其中:
  - 電子郵件地址以 `prisma.io` 結尾_且_
  - 至少有一篇已發布的貼文(關聯查詢)
- 返回所有 `User` 欄位
- 包含所有 `published` 等於 `true` 的相關 `Post` 記錄

<CodeWithResult>
<cmd>

```ts
const result = await prisma.user.findMany({
  where: {
    email: {
      endsWith: 'prisma.io',
    },
    posts: {
      some: {
        published: true,
      },
    },
  },
  include: {
    posts: {
      where: {
        published: true,
      },
    },
  },
})
```

</cmd>
<cmdResult>

```json5 no-copy
[
  {
    id: 1,
    name: 'Ellen',
    email: 'ellen@prisma.io',
    role: 'USER',
    posts: [
      {
        id: 1,
        title: 'How to build a house',
        published: true,
        authorId: 1,
      },
      {
        id: 2,
        title: 'How to cook kohlrabi',
        published: true,
        authorId: 1,
      },
    ],
  },
]
```

</cmdResult>
</CodeWithResult>

### 篩選條件和運算子

請參閱 Prisma Client 的參考文件以獲取[完整的運算子清單](/orm/reference/prisma-client-reference#filter-conditions-and-operators),例如 `startsWith` 和 `contains`。

#### 組合運算子

您可以使用運算子(例如 [`NOT`](/orm/reference/prisma-client-reference#not-1) 和 [`OR`](/orm/reference/prisma-client-reference#or))來根據條件組合進行篩選。以下查詢返回所有 `email` 以 `gmail.com` 或 `company.com` 結尾的使用者,但排除以 `admin.company.com` 結尾的任何電子郵件

<CodeWithResult>
<cmd>

```ts
const result = await prisma.user.findMany({
  where: {
    OR: [
      {
        email: {
          endsWith: 'gmail.com',
        },
      },
      { email: { endsWith: 'company.com' } },
    ],
    NOT: {
      email: {
        endsWith: 'admin.company.com',
      },
    },
  },
  select: {
    email: true,
  },
})
```

</cmd>
<cmdResult>

```json5 no-copy
[{ email: 'alice@gmail.com' }, { email: 'bob@company.com' }]
```

</cmdResult>
</CodeWithResult>

### 對 null 欄位進行篩選

以下查詢返回所有 `content` 欄位為 `null` 的貼文:

```ts
const posts = await prisma.post.findMany({
  where: {
    content: null,
  },
})
```

### 對非 null 欄位進行篩選

以下查詢返回所有 `content` 欄位**不是** `null` 的貼文:

```ts
const posts = await prisma.post.findMany({
  where: {
    content: { not: null },
  },
})
```

### 對關聯進行篩選

Prisma Client 支援[對相關記錄進行篩選](/orm/prisma-client/queries/relation-queries#relation-filters)。例如,在以下 schema 中,使用者可以有多篇部落格貼文:

```prisma highlight=5,12-13;normal
model User {
  id    Int     @id @default(autoincrement())
  name  String?
  email String  @unique
  //highlight-next-line
  posts Post[] // User can have many posts
}

model Post {
  id        Int     @id @default(autoincrement())
  title     String
  published Boolean @default(true)
  //highlight-start
  author    User    @relation(fields: [authorId], references: [id])
  authorId  Int
  //highlight-end
}
```

`User` 和 `Post` 之間的一對多關聯允許您根據貼文查詢使用者 - 例如,以下查詢返回所有_至少有一篇_貼文 (`some`) 瀏覽次數超過 10 的使用者:

```ts
const result = await prisma.user.findMany({
  where: {
    posts: {
      some: {
        views: {
          gt: 10,
        },
      },
    },
  },
})
```

您也可以根據作者的屬性查詢貼文。例如,以下查詢返回所有作者的 `email` 包含 `"prisma.io"` 的貼文:

```ts
const res = await prisma.post.findMany({
  where: {
    author: {
      email: {
        contains: 'prisma.io',
      },
    },
  },
})
```

### 對純量清單/陣列進行篩選

純量清單(例如 `String[]`)有一組特殊的[篩選條件](/orm/reference/prisma-client-reference#scalar-list-filters) - 例如,以下查詢返回所有 `tags` 陣列包含 `databases` 的貼文:

```ts
const posts = await client.post.findMany({
  where: {
    tags: {
      has: 'databases',
    },
  },
})
```

### 不區分大小寫的篩選

不區分大小寫的篩選[作為 PostgreSQL 和 MongoDB 提供者的功能可用](/orm/prisma-client/queries/case-sensitivity#options-for-case-insensitive-filtering)。MySQL、MariaDB 和 Microsoft SQL Server 預設不區分大小寫,不需要 Prisma Client 功能來實現不區分大小寫的篩選。

要使用不區分大小寫的篩選,請向特定篩選器新增 `mode` 屬性並指定 `insensitive`:

```ts highlight=5;normal
const users = await prisma.user.findMany({
  where: {
    email: {
      endsWith: 'prisma.io',
      mode: 'insensitive', // Default value: default
    },
    name: {
      equals: 'Archibald', // Default mode
    },
  },
})
```

另請參閱: [大小寫敏感性](/orm/prisma-client/queries/case-sensitivity)

### 篩選常見問題

#### 篩選在資料庫層級如何運作?

對於 MySQL 和 PostgreSQL,Prisma Client 使用 [`LIKE`](https://www.w3schools.com/sql/sql_like.asp)(和 [`ILIKE`](https://www.postgresql.org/docs/current/functions-matching.html#FUNCTIONS-LIKE))運算子來搜尋給定的模式。這些運算子具有內建的模式匹配,使用 `LIKE` 特有的符號。模式匹配符號包括 `%` 表示零個或多個字元(類似於其他正規表示式實現中的 `*`)和 `_` 表示一個字元(類似於 `.`)

要匹配字面字元 `%` 或 `_`,請確保轉義這些字元。例如:


```ts
const users = await prisma.user.findMany({
  where: {
    name: {
      startsWith: '_benny',
    },
  },
})
```


上述查詢將匹配名字以一個字元後接 `benny` 開頭的任何使用者,例如 `7benny` 或 `&benny`。如果您想要找到名字以字面字串 `_benny` 開頭的任何使用者,您可以這樣做:


```ts highlight=4
const users = await prisma.user.findMany({
  where: {
    name: {
      startsWith: '\\_benny', // note that the `_` character is escaped, preceding `\` with `\` when included in a string
    },
  },
})
```


## 排序

使用 [`orderBy`](/orm/reference/prisma-client-reference#orderby) 根據特定欄位或欄位集對記錄清單或巢狀記錄清單進行排序。例如,以下查詢返回按 `role` 和 `name` 排序的所有 `User` 記錄,**並且**每個使用者的貼文按 `title` 排序:

<CodeWithResult>

<cmd>

```ts
const usersWithPosts = await prisma.user.findMany({
  orderBy: [
    {
      role: 'desc',
    },
    {
      name: 'desc',
    },
  ],
  include: {
    posts: {
      orderBy: {
        title: 'desc',
      },
      select: {
        title: true,
      },
    },
  },
})
```

</cmd>

<cmdResult>

```json no-copy
[
  {
    "email": "kwame@prisma.io",
    "id": 2,
    "name": "Kwame",
    "role": "USER",
    "posts": [
      {
        "title": "Prisma in five minutes"
      },
      {
        "title": "Happy Table Friends: Relations in Prisma"
      }
    ]
  },
  {
    "email": "emily@prisma.io",
    "id": 5,
    "name": "Emily",
    "role": "USER",
    "posts": [
      {
        "title": "Prisma Day 2020"
      },
      {
        "title": "My first day at Prisma"
      },
      {
        "title": "All about databases"
      }
    ]
  }
]
```

</cmdResult>

</CodeWithResult>

> **注意**: 您也可以[對巢狀記錄清單進行排序](/orm/prisma-client/queries/relation-queries#filter-a-list-of-relations)以透過 ID 檢索單一記錄。

### 根據關聯排序

您也可以根據關聯的屬性進行排序。例如,以下查詢根據作者的電子郵件地址對所有貼文進行排序:

```ts
const posts = await prisma.post.findMany({
  orderBy: {
    author: {
      email: 'asc',
    },
  },
})
```

### 根據關聯聚合值排序

在 [2.19.0](https://github.com/prisma/prisma/releases/2.19.0) 及更高版本中,您可以根據**相關記錄的計數**進行排序。

例如,以下查詢根據相關貼文的數量對使用者進行排序:

```ts
const getActiveUsers = await prisma.user.findMany({
  take: 10,
  orderBy: {
    posts: {
      _count: 'desc',
    },
  },
})
```

> **注意**: 目前無法[返回關聯的計數](https://github.com/prisma/prisma/issues/5079)。

### 根據相關性排序(PostgreSQL 和 MySQL)

在 PostgreSQL 的 [3.5.0+](https://github.com/prisma/prisma/releases/3.5.0) 和 MySQL 的 [3.8.0+](https://github.com/prisma/prisma/releases/3.8.0) 中,您可以使用 `_relevance` 關鍵字根據與查詢的相關性對記錄進行排序。這使用了全文搜尋功能中的相關性排名函式。

此功能在 [PostgreSQL 文件](https://www.postgresql.org/docs/12/textsearch-controls.html)和 [MySQL 文件](https://dev.mysql.com/doc/refman/8.0/en/fulltext-search.html)中有進一步說明。

**對於 PostgreSQL**,您需要使用 `fullTextSearchPostgres` [預覽功能](/orm/prisma-client/queries/full-text-search)啟用根據相關性排序:

```prisma
generator client {
  provider        = "prisma-client"
  output          = "./generated"
  previewFeatures = ["fullTextSearchPostgres"]
}
```

根據相關性排序可以單獨使用,也可以與 `search` 篩選器一起使用:`_relevance` 用於排序清單,而 `search` 篩選未排序的清單。

例如,以下查詢使用 `_relevance` 在 `bio` 欄位中根據術語 `developer` 進行篩選,然後以_降序_方式根據相關性對結果進行排序:

```ts
const getUsersByRelevance = await prisma.user.findMany({
  take: 10,
  orderBy: {
    _relevance: {
      fields: ['bio'],
      search: 'developer',
      sort: 'desc',
    },
  },
})
```

<br />

:::note

在 Prisma ORM 5.16.0 之前,啟用 `fullTextSearch` 預覽功能會將 `<Model>OrderByWithRelationInput` TypeScript 類型重新命名為 `<Model>OrderByWithRelationAndSearchRelevanceInput`。如果您正在使用預覽功能,您需要更新類型匯入。

:::


### 將 null 記錄排序在最前面或最後面

:::info

注意事項:

- 此功能在版本 `4.16.0` 及更高版本中正式可用。要在版本 [`4.1.0`](https://github.com/prisma/prisma/releases/tag/4.1.0) 到 [`4.15.0`](https://github.com/prisma/prisma/releases/tag/4.15.0) 中使用此功能,需要啟用[預覽功能](/orm/reference/preview-features/client-preview-features#enabling-a-prisma-client-preview-feature) `orderByNulls`。
- 此功能不適用於 MongoDB。
- 您只能對可選的[純量](/orm/prisma-schema/data-model/models#scalar-fields)欄位按 null 排序。如果您嘗試對必填或[關聯](/orm/prisma-schema/data-model/models#relation-fields)欄位按 null 排序,Prisma Client 會拋出 [P2009 錯誤](/orm/reference/error-reference#p2009)。

:::

您可以對結果進行排序,使具有 `null` 欄位的記錄顯示在最前面或最後面。

如果 `name` 是可選欄位,則以下使用 `last` 的查詢會根據 `name` 對使用者進行排序,`null` 記錄在最後:

```ts
const users = await prisma.user.findMany({
  orderBy: {
    // highlight-next-line
    updatedAt: { sort: 'asc', nulls: 'last' },
  },
})
```

如果您希望具有 `null` 值的記錄顯示在返回陣列的開頭,請使用 `first`:

```ts
const users = await prisma.user.findMany({
  orderBy: {
    // highlight-next-line
    updatedAt: { sort: 'asc', nulls: 'first' },
  },
})
```

請注意,`first` 也是預設值,因此如果您省略 `null` 選項,`null` 值將顯示在返回陣列的最前面。
