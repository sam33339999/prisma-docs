Prisma Client 是一個根據您的資料庫 schema 量身打造的生成資料庫客戶端。預設情況下,Prisma Client 會生成到 `node_modules/.prisma/client` 資料夾,但我們強烈建議[您指定輸出位置](#using-a-custom-output-path)。

:::warning

在 Prisma ORM 7 中,Prisma Client 將不再預設生成在 `node_modules` 中,並且需要定義輸出路徑。[在下方了解更多關於如何定義輸出路徑](#using-a-custom-output-path)。

:::

:::tip 使用不含 Rust 二進位檔的 Prisma ORM

如果 Prisma ORM 的 Rust 引擎二進位檔導致大型套件大小、緩慢建置或部署問題(例如在 serverless 或 edge 環境中),您可以使用此 `generator` 區塊配置來使用它而不需要它們:

```prisma
generator client {
  provider   = "prisma-client"
  output     = "./generated"
  engineType = "client"
}
```

不含 Rust 二進位檔的 Prisma ORM 自 [v6.16.0](https://pris.ly/release/6.16.0) 起已[正式可用](/orm/more/releases#generally-available-ga)。

請注意,在這種情況下您需要使用[驅動程式適配器](/orm/overview/databases/database-drivers#driver-adapters)。

使用此架構時:

- 不會下載或交付 Rust 查詢引擎二進位檔。
- 資料庫連線池由您安裝的原生 JS 資料庫驅動程式維護(例如,PostgreSQL 的 `@prisma/adapter-pg`)。

此設定可以簡化 serverless 或 edge 執行環境中的部署。在[此處的文件](/orm/prisma-client/setup-and-configuration/no-rust-engine)中了解更多。

:::


要生成和實例化 Prisma Client:

1. 確保您已在機器上[安裝 Prisma CLI](/orm/tools/prisma-cli#installation)。

   ```terminal
   npm install prisma --save-dev
   ```

1. 將以下 `generator` 定義加入您的 Prisma schema:

   ```prisma
   generator client {
     provider = "prisma-client"
     output   = "./generated"
   }
   ```

   :::note

   請隨意自訂輸出位置以符合您的應用程式。常見的目錄有 `prisma`、`src`,甚至是您專案的根目錄。

   :::

1. 安裝 `@prisma/client` npm 套件:

   ```terminal
   npm install @prisma/client
   ```

1. 使用以下指令生成 Prisma Client:

   ```terminal
   npx prisma generate
   ```

1. 您現在可以在程式碼中[實例化 Prisma Client](/orm/prisma-client/setup-and-configuration/instantiate-prisma-client):

    ```ts
    import { PrismaClient } from './prisma/generated/client'
    const prisma = new PrismaClient()
    // use `prisma` in your application to read and write data in your DB
    ```

> **重要**: 在您對 Prisma schema 進行任何變更後,您需要重新執行 `prisma generate` 指令以更新生成的 Prisma Client 程式碼。

## Prisma Client 的位置

:::warning

我們強烈建議您定義自訂的 `output` 路徑。在 Prisma ORM 版本 `6.6.0` 中,不定義 `output` 路徑將導致警告。在 Prisma ORM 7 中,此欄位將是必需的。

:::

### 使用自訂 `output` 路徑

您也可以在 `generator` 配置中指定自訂的 `output` 路徑,例如(假設您的 `schema.prisma` 檔案位於預設的 `prisma` 子資料夾):

```prisma
generator client {
  provider = "prisma-client"
  output   = "../src/generated/"
}
```

在為該 schema 檔案執行 `prisma generate` 後,Prisma Client 套件將位於:

```
./src/generated/client
```

要從自訂位置匯入 `PrismaClient`(例如,從名為 `./src/script.ts` 的檔案):

```ts
import { PrismaClient } from './generated/client'
```

:::note


為了提升與 ECMAScript 模組 (ESM) 的相容性,並確保 Prisma ORM 在不同 Node.js 執行環境中的一致行為,您也可以使用較新的 [`prisma-client`](/orm/prisma-schema/overview/generators#prisma-client) 生成器。此生成器專門設計用於處理模組解析和執行環境變化的常見挑戰,提供更順暢的整合體驗和更少的打包工具摩擦。

:::

## 載入環境變數

要在您的 Prisma 應用程式中載入環境變數,您可以使用 `prisma.config.ts` 檔案以及來自 `prisma/config` 的 `env` 輔助函式。此方法提供更好的型別安全性和配置管理。

1. 首先,安裝所需的依賴項:

   ```bash
   npm install dotenv --save-dev
   ```

2. 在您的專案根目錄中建立 `.env` 檔案(如果它不存在)並加入您的資料庫連線字串:

   ```env
   DATABASE_URL="your_database_connection_string_here"
   ```

3. 在您的專案根目錄中更新 `prisma.config.ts` 檔案:

   ```ts
   import "dotenv/config";
   import { defineConfig, env } from "prisma/config";

   export default defineConfig({
      schema: "prisma/schema.prisma",
      migrations: {
        path: "prisma/migrations"
      },
      datasource: {
         url: env("DATABASE_URL"),
      },
   });
   ```

## `@prisma/client` npm 套件

`@prisma/client` npm 套件由兩個關鍵部分組成:

- `@prisma/client` 模組本身,僅在您重新安裝套件時才會變更
- `.prisma/client` 資料夾,這是從您的 schema 生成的獨特 Prisma Client 的[預設位置](#using-a-custom-output-path)

`@prisma/client/index.d.ts` 匯出 `.prisma/client`:

```ts
export * from '.prisma/client'
```

這意味著您仍然在自己的 `.ts` 檔案中匯入 `@prisma/client`:

```ts
import { PrismaClient } from '@prisma/client'
```

Prisma Client 從您的 Prisma schema 生成,並且是您專案獨有的。每次您變更 schema(例如,透過執行 [schema 遷移](/orm/prisma-migrate))並執行 `prisma generate` 時,Prisma Client 的程式碼都會變更:

![The .prisma and @prisma folders](./prisma-client-node-module.png)

`.prisma` 資料夾不受 Node.js 套件管理器中的[修剪](https://docs.npmjs.com/cli/prune.html)影響。
