## 設定

### 1. 前置需求

為了設定 Prisma Client,您需要一個包含資料庫連線、Prisma Client 生成器和至少一個模型的 [Prisma schema 檔案](/orm/prisma-schema):

```prisma file=schema.prisma
datasource db {
  provider = "postgresql"
}

generator client {
  provider = "prisma-client"
  output   = "../src/generated/prisma"
}

model User {
  id        Int      @id @default(autoincrement())
  createdAt DateTime @default(now())
  email     String   @unique
  name      String?
}
```

同時請確保[安裝 Prisma CLI](/orm/tools/prisma-cli#installation):

```
npm install prisma --save-dev
npx prisma
```

### 2. 安裝

使用以下指令在您的專案中安裝 Prisma Client:

```
npm install @prisma/client
```

### 3. 匯入 Prisma Client

根據您的使用情境,有多種方式可以在您的專案中匯入 Prisma Client:

<TabbedContent code>

<TabItem value="TypeScript">

```ts
import { PrismaClient } from './generated/prisma'

const prisma = new PrismaClient()
// use `prisma` in your application to read and write data in your DB
```

</TabItem>

<TabItem value="JavaScript">

```js
const { PrismaClient } = require('./generated/prisma')

const prisma = new PrismaClient()
// use `prisma` in your application to read and write data in your DB
```

</TabItem>

</TabbedContent>

對於 edge 環境,您可以如下匯入 Prisma Client:

<TabbedContent code>

<TabItem value="TypeScript">

```ts
import { PrismaClient } from './generated/prisma/edge'

const prisma = new PrismaClient()
// use `prisma` in your application to read and write data in your DB
```

</TabItem>

<TabItem value="JavaScript">

```js
const { PrismaClient } = require('./generated/prisma/edge')

const prisma = new PrismaClient()
// use `prisma` in your application to read and write data in your DB
```

</TabItem>

</TabbedContent>

> **注意**: 如果您使用[驅動程式適配器](/orm/overview/databases/database-drivers#driver-adapters),您可以直接從生成器的 `output` 路徑指定位置匯入,例如 `./src/generated/prisma`。不需要從 `./src/generated/prisma/edge` 匯入。

### 4. 使用 Prisma Client 向您的資料庫發送查詢

一旦您實例化了 `PrismaClient`,您就可以在程式碼中開始發送查詢:

```ts
// run inside `async` function
const newUser = await prisma.user.create({
  data: {
    name: 'Alice',
    email: 'alice@prisma.io',
  },
})

const users = await prisma.user.findMany()
```

:::info

所有 Prisma Client 方法都會回傳一個 [`PrismaPromise`](/orm/reference/prisma-client-reference#prismapromise-behavior) 實例,只有在您呼叫 `await` 或 `.then()` 或 `.catch()` 時才會執行。

:::

### 5. 演進您的應用程式

每當您對資料庫進行變更並反映在 Prisma schema 中時,您需要手動重新生成 Prisma Client 以更新輸出目錄中的生成程式碼:

```
prisma generate
```
