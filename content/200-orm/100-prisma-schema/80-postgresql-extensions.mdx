本頁面介紹 [PostgreSQL 擴充功能](https://www.postgresql.org/docs/current/external-extensions.html)，並說明如何在 Prisma ORM 中使用它們。

:::warning

在 Prisma ORM v4.5.0 和 v6.16.0 之間，您可以透過 `postgresqlExtensions` 預覽功能旗標在 Prisma schema 中啟用擴充功能。此功能旗標已在 v6.16.0 中棄用，現在使用 PostgreSQL 擴充功能的建議方法是透過[自訂遷移](/orm/prisma-migrate/workflows/customizing-migrations)來安裝它們。

:::

## 什麼是 PostgreSQL 擴充功能？

PostgreSQL 允許您透過安裝和啟用稱為_擴充功能_的套件來擴充您的資料庫功能。例如，`citext` 擴充功能加入了不區分大小寫的字串資料類型。某些擴充功能（如 `citext`）由 PostgreSQL 直接提供，而其他擴充功能則由外部開發。有關擴充功能的更多資訊，請參閱 [PostgreSQL 文件](https://www.postgresql.org/docs/current/sql-createextension.html)。

若要使用擴充功能，必須先將其_安裝_在資料庫伺服器的本機檔案系統上。然後需要_啟用_擴充功能，這會執行一個加入新功能的指令檔。

## 在 Prisma ORM 中使用 PostgreSQL 擴充功能

讓我們逐步介紹安裝 `citext` 擴充功能的範例。

### 1. 建立空白遷移

執行以下指令以建立一個您可以[自訂](/orm/prisma-migrate/workflows/customizing-migrations)的空白遷移：

```terminal
npx prisma migrate dev --create-only
```

### 2. 加入安裝擴充功能的 SQL 陳述式

在 `migrations` 目錄中建立的新遷移檔案中，加入以下陳述式：

```sql
CREATE EXTENSION IF NOT EXISTS citext;
```

### 3. 部署遷移

執行以下指令以部署遷移並套用到您的資料庫：

```terminal
npx prisma migrate deploy
```

### 4. 使用擴充功能

您現在可以在 Prisma Client 的查詢中使用擴充功能。如果擴充功能具有目前無法在 Prisma schema 中原生表示的特殊資料類型，您仍然可以使用 [`Unsupported`](/orm/prisma-schema/data-model/models#unsupported-types) 後備類型在模型上定義該類型的欄位。
