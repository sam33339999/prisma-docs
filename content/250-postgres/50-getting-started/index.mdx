## 快速入門

要**使用 Prisma Postgres 資料庫建立新的 Prisma ORM 專案**，請在終端機中執行以下指令：

```terminal
npx prisma init --db
```

執行此指令後，終端機會引導您進行下一步。請依照[此頁面](/getting-started/prisma-postgres/from-the-cli)完成您第一個 Prisma Postgres 專案的設定。

如果您需要快速建立資料庫進行測試，或想嘗試 Prisma Postgres，可以執行以下指令來建立一個臨時的 24 小時資料庫：

```terminal
npx create-db@latest
```

您可以在[專門文件](/postgres/introduction/npx-create-db)中了解更多關於 `npx create-db` 的資訊。

## 透過任何資料庫函式庫或工具連接

您可以使用任何您選擇的 ORM 或資料庫工具來存取 Prisma Postgres。一旦您取得連接字串，就可以遵循任何 ORM 或資料庫工具的 PostgreSQL 設定文件：

- [Drizzle ORM](https://orm.drizzle.team/docs/get-started/postgresql-new)
- [Kysely](https://kysely.dev/docs/getting-started)
- [TypeORM](https://typeorm.io/#installation)
- [Sequelize](https://sequelize.org/docs/v6/getting-started/)
- [MikroORM](https://mikro-orm.io/docs/quick-start)
- [node-postgres](https://node-postgres.com/)
