[CockroachDB](https://www.cockroachlabs.com/) 是一個專為雲端應用程式設計的分散式 SQL 資料庫，提供水平擴展性、強一致性和高可用性。在本指南中，您將學習如何將 Prisma ORM 加入現有的 TypeScript 專案、將其連接到 CockroachDB、自省現有的資料庫架構，並開始使用型別安全的 Prisma Client 進行查詢。

## 前置需求

<Prerequisites />

## 1. 設定 Prisma ORM

導航至您現有的專案目錄並安裝所需的相依套件：

```terminal
npm install prisma @types/node @types/pg --save-dev
npm install @prisma/client @prisma/adapter-pg pg dotenv
```

以下是各套件的功能說明：

- **`prisma`** - Prisma CLI，用於執行 `prisma init`、`prisma db pull` 和 `prisma generate` 等指令
- **`@prisma/client`** - Prisma Client 函式庫，用於查詢您的資料庫
- **`@prisma/adapter-pg`** - [`node-postgres` driver adapter](/orm/overview/databases/postgresql#using-the-node-postgres-driver)，將 Prisma Client 連接到您的資料庫（CockroachDB 與 PostgreSQL 相容）
- **`pg`** - node-postgres 資料庫驅動程式
- **`@types/pg`** - node-postgres 的 TypeScript 型別定義
- **`dotenv`** - 從您的 `.env` 檔案載入環境變數

## 2. 初始化 Prisma ORM

使用以下指令建立 [Prisma Schema](/orm/prisma-schema) 檔案，設定您的 Prisma ORM 專案：

```terminal
npx prisma init --datasource-provider cockroachdb --output ../generated/prisma
```

此指令會執行以下幾項操作：

- 建立包含 `schema.prisma` 檔案的 `prisma/` 目錄，其中包含您的資料庫連線設定
- 在根目錄中建立用於環境變數的 `.env` 檔案
- 建立用於 Prisma 設定的 `prisma.config.ts` 檔案

產生的 `prisma.config.ts` 檔案如下所示：

```typescript file=prisma.config.ts
import 'dotenv/config'
import { defineConfig, env } from 'prisma/config'

export default defineConfig({
  schema: 'prisma/schema.prisma',
  migrations: {
    path: 'prisma/migrations',
  },
  datasource: {
    url: env('DATABASE_URL'),
  },
})
```

產生的 schema 使用 [ESM-first `prisma-client` generator](/orm/prisma-schema/overview/generators#prisma-client) 並具有自訂輸出路徑：

```prisma file=prisma/schema.prisma
generator client {
  provider = "prisma-client"
  output   = "../generated/prisma"
}

datasource db {
  provider = "cockroachdb"
}
```

## 3. 連接您的資料庫

使用您的 CockroachDB 連線 URL 更新 `.env` 檔案：

```bash file=.env
DATABASE_URL="postgresql://user:password@host:26257/mydb?sslmode=require"
```

CockroachDB 的[連線 URL 格式](/orm/reference/connection-urls)如下：

```
postgresql://USER:PASSWORD@HOST:PORT/DATABASE?sslmode=require
```

## 4. 自省您的資料庫

執行以下指令以自省您現有的資料庫：

```terminal
npx prisma db pull
```

此指令會讀取 `DATABASE_URL` 環境變數，連接到您的資料庫，並自省資料庫架構。然後將資料庫架構從 SQL 轉譯為 Prisma schema 中的資料模型。

![Introspect your database with Prisma ORM](/img/getting-started/prisma-db-pull-generate-schema.png)

自省完成後，您的 Prisma schema 將包含代表現有資料庫表格的模型。

## 5. 為您的資料庫建立基準

要在現有資料庫中使用 Prisma Migrate，您需要[為資料庫建立基準](/orm/prisma-migrate/getting-started)。

首先，建立 `migrations` 目錄：

```terminal
mkdir -p prisma/migrations/0_init
```

接下來，使用 `prisma migrate diff` 產生遷移檔案：

```terminal
npx prisma migrate diff --from-empty --to-schema prisma/schema.prisma --script > prisma/migrations/0_init/migration.sql
```

檢查產生的遷移檔案，確保它與您的資料庫架構相符。

然後，將遷移標記為已套用：

```terminal
npx prisma migrate resolve --applied 0_init
```

您現在已為目前的資料庫架構建立了基準。

## 6. 產生 Prisma ORM 型別

基於自省的 schema 產生 Prisma Client：

```terminal
npx prisma generate
```

這會在 `generated/prisma` 目錄中建立針對您資料庫架構的型別安全 Prisma Client。

## 7. 實例化 Prisma Client

建立一個工具檔案來實例化 Prisma Client。您需要將 Prisma ORM 的 driver adapter 實例傳遞給 `PrismaClient` 建構函式：

```typescript file=lib/prisma.ts
import "dotenv/config";
import { PrismaPg } from '@prisma/adapter-pg'
import { PrismaClient } from '../generated/prisma/client'

const connectionString = `${process.env.DATABASE_URL}`

const adapter = new PrismaPg({ connectionString })
const prisma = new PrismaClient({ adapter })

export { prisma }
```

## 8. 查詢您的資料庫

現在您可以使用 Prisma Client 來查詢資料庫。建立一個 `script.ts` 檔案：

```typescript file=script.ts
import { prisma } from './lib/prisma'

async function main() {
  // Example: Fetch all records from a table
  // Replace 'user' with your actual model name
  const allUsers = await prisma.user.findMany()
  console.log('All users:', JSON.stringify(allUsers, null, 2))
}

main()
  .then(async () => {
    await prisma.$disconnect()
  })
  .catch(async (e) => {
    console.error(e)
    await prisma.$disconnect()
    process.exit(1)
  })
```

執行腳本：

```terminal
npx tsx script.ts
```

## 9. 演進您的 schema

要對資料庫架構進行變更：

### 9.1. 更新您的 Prisma schema 檔案

更新您的 Prisma schema 檔案以反映您想對資料庫架構進行的變更。例如，新增一個新模型：

```prisma file=prisma/schema.prisma
// add-start
model Post {
  id        Int      @id @default(autoincrement())
  title     String
  content   String?
  published Boolean  @default(false)
  authorId  Int
  author    User     @relation(fields: [authorId], references: [id])
}

model User {
  id    Int    @id @default(autoincrement())
  email String @unique
  name  String?
  posts Post[]
}
// add-end
```

### 9.2. 建立並套用遷移：

```terminal
npx prisma migrate dev --name your_migration_name
```

此指令將會：
- 建立新的 SQL 遷移檔案
- 將遷移套用至您的資料庫
- 重新產生 Prisma Client

## 10. 探索您的資料

探索 [CockroachDB](https://www.cockroachlabs.com/blog/cockroachdb-gui-options/) 建議的選項來檢視和管理您的資料。

[Prisma Studio](/orm/tools/prisma-studio) 目前不支援 CockroachDB。未來版本可能會加入支援。更多資訊請參閱 [Databases supported by Prisma Studio](/orm/tools/prisma-studio#databases-supported-by-prisma-studio)。
