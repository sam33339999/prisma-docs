[Prisma Postgres](/postgres) 是一個完全託管的 PostgreSQL 資料庫，可以縮放至零並與 Prisma ORM 和 Prisma Studio 順暢整合。在本指南中，你將學習如何將 Prisma ORM 加入現有的 TypeScript 專案、連接到 Prisma Postgres、內省你現有的資料庫架構，並開始使用型別安全的 Prisma Client 進行查詢。

## 前置需求

<Prerequisites />

## 1. 設定 Prisma ORM

導航到你現有的專案目錄並安裝所需的相依套件：

```terminal
npm install prisma @types/node @types/pg --save-dev
npm install @prisma/client @prisma/adapter-pg pg dotenv
```

以下是各個套件的功能：

- **`prisma`** - Prisma CLI，用於執行 `prisma init`、`prisma db pull` 和 `prisma generate` 等指令
- **`@prisma/client`** - Prisma Client 函式庫，用於查詢你的資料庫
- **`@prisma/adapter-pg`** - [`node-postgres` 驅動程式適配器](/orm/overview/databases/postgresql#using-the-node-postgres-driver)，連接 Prisma Client 到你的資料庫
- **`pg`** - node-postgres 資料庫驅動程式
- **`@types/pg`** - node-postgres 的 TypeScript 型別定義
- **`dotenv`** - 從你的 `.env` 檔案載入環境變數

## 2. 初始化 Prisma ORM

透過以下指令建立你的 [Prisma Schema](/orm/prisma-schema) 檔案來設定 Prisma ORM 專案：

```terminal
npx prisma init --datasource-provider postgresql --output ../generated/prisma
```

此指令會執行以下操作：

- 建立 `prisma/` 目錄，包含一個 `schema.prisma` 檔案，其中包含你的資料庫連線配置
- 在根目錄建立 `.env` 檔案，用於環境變數
- 建立 `prisma.config.ts` 檔案，用於 Prisma 配置

產生的 `prisma.config.ts` 檔案如下：

```typescript file=prisma.config.ts
import 'dotenv/config'
import { defineConfig, env } from 'prisma/config'

export default defineConfig({
  schema: 'prisma/schema.prisma',
  migrations: {
    path: 'prisma/migrations',
  },
  datasource: {
    url: env('DATABASE_URL'),
  },
})
```

產生的 schema 使用 [ESM 優先的 `prisma-client` 產生器](/orm/prisma-schema/overview/generators#prisma-client) 並帶有自訂輸出路徑：

```prisma file=prisma/schema.prisma
generator client {
  provider = "prisma-client"
  output   = "../generated/prisma"
}

datasource db {
  provider = "postgresql"
}
```

## 3. 連接你的資料庫

使用你的 Prisma Postgres 連線 URL 更新 `.env` 檔案：

```bash file=.env
DATABASE_URL="postgresql://user:password@host:5432/database?schema=public"
```

將佔位值替換為你實際的 Prisma Postgres 連線詳細資料。

## 4. 內省你的資料庫

執行以下指令來內省你現有的資料庫：

```terminal
npx prisma db pull
```

此指令會讀取 `DATABASE_URL` 環境變數、連接到你的資料庫，並內省資料庫架構。然後將資料庫架構從 SQL 轉換為你 Prisma schema 中的資料模型。

![使用 Prisma ORM 內省你的資料庫](/img/getting-started/prisma-db-pull-generate-schema.png)

內省後，你的 Prisma schema 將包含代表現有資料庫資料表的模型。

## 5. 為你的資料庫建立基準

若要在現有資料庫上使用 Prisma Migrate，你需要[為資料庫建立基準](/orm/prisma-migrate/getting-started)。

首先，建立 `migrations` 目錄：

```terminal
mkdir -p prisma/migrations/0_init
```

接下來，使用 `prisma migrate diff` 產生遷移檔案：

```terminal
npx prisma migrate diff --from-empty --to-schema prisma/schema.prisma --script > prisma/migrations/0_init/migration.sql
```

檢視產生的遷移檔案，確保它符合你的資料庫架構。

然後，將遷移標記為已套用：

```terminal
npx prisma migrate resolve --applied 0_init
```

現在你已經為當前的資料庫架構建立了基準。

## 6. 產生 Prisma ORM 型別

根據你內省的 schema 產生 Prisma Client：

```terminal
npx prisma generate
```

這會在 `generated/prisma` 目錄中建立一個針對你資料庫架構客製化的型別安全 Prisma Client。

## 7. 實例化 Prisma Client

建立一個工具檔案來實例化 Prisma Client。你需要將 Prisma ORM 驅動程式適配器的實例傳遞給 `PrismaClient` 建構函式：

```typescript file=lib/prisma.ts
import "dotenv/config";
import { PrismaPg } from '@prisma/adapter-pg'
import { PrismaClient } from '../generated/prisma/client'

const connectionString = `${process.env.DATABASE_URL}`

const adapter = new PrismaPg({ connectionString })
const prisma = new PrismaClient({ adapter })

export { prisma }
```

:::tip

如果你需要從邊緣運行環境（Cloudflare Workers、Vercel Edge Functions 等）透過 HTTP 查詢你的資料庫，請使用 [Prisma Postgres serverless 驅動程式](/postgres/database/serverless-driver#use-with-prisma-orm)。

:::

## 8. 查詢你的資料庫

現在你可以使用 Prisma Client 來查詢你的資料庫。建立一個 `script.ts` 檔案：

```typescript file=script.ts
import { prisma } from './lib/prisma'

async function main() {
  // Example: Fetch all records from a table
  // Replace 'user' with your actual model name
  const allUsers = await prisma.user.findMany()
  console.log('All users:', JSON.stringify(allUsers, null, 2))
}

main()
  .then(async () => {
    await prisma.$disconnect()
  })
  .catch(async (e) => {
    console.error(e)
    await prisma.$disconnect()
    process.exit(1)
  })
```

執行腳本：

```terminal
npx tsx script.ts
```

## 9. 演化你的 schema

若要對資料庫架構進行變更：

### 9.1. 更新你的 Prisma schema 檔案

更新你的 Prisma schema 檔案以反映你想對資料庫架構進行的變更。例如，新增一個新模型：

```prisma file=prisma/schema.prisma
// add-start
model Post {
  id        Int      @id @default(autoincrement())
  title     String
  content   String?
  published Boolean  @default(false)
  authorId  Int
  author    User     @relation(fields: [authorId], references: [id])
}

model User {
  id    Int    @id @default(autoincrement())
  email String @unique
  name  String?
  posts Post[]
}
// add-end
```

### 9.2. 建立並套用遷移：

```terminal
npx prisma migrate dev --name your_migration_name
```

此指令將：
- 建立一個新的 SQL 遷移檔案
- 將遷移套用到你的資料庫
- 重新產生 Prisma Client
