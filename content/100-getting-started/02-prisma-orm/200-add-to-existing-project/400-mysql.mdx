[MySQL](https://www.mysql.com/) 是一個被廣泛使用的開源關聯式資料庫管理系統,以其速度、可靠性和易用性著稱。在本指南中,您將學習如何將 Prisma ORM 加入現有的 TypeScript 專案、將其連接至 MySQL、自檢現有的資料庫結構,並開始使用型別安全的 Prisma Client 進行查詢。

## 先決條件

<Prerequisites />

## 1. 設定 Prisma ORM

導航至您現有的專案目錄並安裝所需的相依套件:

```terminal
npm install prisma @types/node --save-dev
npm install @prisma/client @prisma/adapter-mariadb dotenv
```

以下是各個套件的功能:

- **`prisma`** - 用於執行 `prisma init`、`prisma db pull` 和 `prisma generate` 等指令的 Prisma CLI
- **`@prisma/client`** - 用於查詢資料庫的 Prisma Client 函式庫
- **`@prisma/adapter-mariadb`** - 將 Prisma Client 連接至資料庫的 MySQL/MariaDB 驅動程式適配器
- **`dotenv`** - 從 `.env` 檔案載入環境變數

## 2. 初始化 Prisma ORM

使用以下指令建立 [Prisma Schema](/orm/prisma-schema) 檔案來設定您的 Prisma ORM 專案:

```terminal
npx prisma init --datasource-provider mysql --output ../generated/prisma
```

此指令會執行以下幾項操作:

- 建立包含 `schema.prisma` 檔案的 `prisma/` 目錄,其中包含您的資料庫連線設定
- 在根目錄中建立用於環境變數的 `.env` 檔案
- 建立用於 Prisma 設定的 `prisma.config.ts` 檔案

生成的 `prisma.config.ts` 檔案如下所示:

```typescript file=prisma.config.ts
import 'dotenv/config'
import { defineConfig, env } from 'prisma/config'

export default defineConfig({
  schema: 'prisma/schema.prisma',
  migrations: {
    path: 'prisma/migrations',
  },
  datasource: {
    url: env('DATABASE_URL'),
  },
})
```

生成的 schema 使用[優先支援 ESM 的 `prisma-client` 生成器](/orm/prisma-schema/overview/generators#prisma-client)以及自訂輸出路徑:

```prisma file=prisma/schema.prisma
generator client {
  provider = "prisma-client"
  output   = "../generated/prisma"
}

datasource db {
  provider = "mysql"
}
```

## 3. 連接您的資料庫

使用您的 MySQL 連線字串詳細資訊更新 `.env` 檔案:

```bash file=.env
DATABASE_URL="mysql://username:password@localhost:3306/mydb"
//add-start
DATABASE_USER="username"
DATABASE_PASSWORD="password"
DATABASE_NAME="mydb"
DATABASE_HOST="localhost"
DATABASE_PORT=3306
//add-end
```

將佔位符替換為您實際的資料庫憑證:
- `username`: 您的 MySQL 使用者名稱
- `password`: 您的 MySQL 密碼
- `localhost:3306`: 您的 MySQL 主機和連接埠
- `mydb`: 您的資料庫名稱

## 4. 自檢您的資料庫

執行以下指令來自檢您現有的資料庫:

```terminal
npx prisma db pull
```

此指令會讀取 `DATABASE_URL` 環境變數,連接至您的資料庫,並自檢資料庫結構。然後將資料庫結構從 SQL 轉換為 Prisma schema 中的資料模型。

![使用 Prisma ORM 自檢您的資料庫](/img/getting-started/prisma-db-pull-generate-schema.png)

自檢後,您的 Prisma schema 將包含代表現有資料庫資料表的模型。

## 5. 基準化您的資料庫

要在現有資料庫上使用 Prisma Migrate,您需要[基準化您的資料庫](/orm/prisma-migrate/getting-started)。

首先,建立 `migrations` 目錄:

```terminal
mkdir -p prisma/migrations/0_init
```

接下來,使用 `prisma migrate diff` 生成遷移檔案:

```terminal
npx prisma migrate diff --from-empty --to-schema prisma/schema.prisma --script > prisma/migrations/0_init/migration.sql
```

檢閱生成的遷移檔案以確保其與您的資料庫結構相符。

然後,將遷移標記為已套用:

```terminal
npx prisma migrate resolve --applied 0_init
```

現在您已為當前的資料庫結構建立了基準。

## 6. 生成 Prisma ORM 型別

根據您自檢的 schema 生成 Prisma Client:

```terminal
npx prisma generate
```

這會在 `generated/prisma` 目錄中建立針對您資料庫結構量身打造的型別安全 Prisma Client。

## 7. 實例化 Prisma Client

建立一個工具檔案來實例化 Prisma Client。您需要將 Prisma ORM 的驅動程式適配器實例傳遞給 `PrismaClient` 建構函式:

```typescript file=lib/prisma.ts
import "dotenv/config";
import { PrismaMariaDb } from '@prisma/adapter-mariadb';
import { PrismaClient } from '../generated/prisma/client';

const adapter = new PrismaMariaDb({
  host: process.env.DATABASE_HOST,
  user: process.env.DATABASE_USER,
  password: process.env.DATABASE_PASSWORD,
  database: process.env.DATABASE_NAME,
  connectionLimit: 5
});
const prisma = new PrismaClient({ adapter });

export { prisma }
```

## 8. 查詢您的資料庫

現在您可以使用 Prisma Client 來查詢資料庫。建立一個 `script.ts` 檔案:

```typescript file=script.ts
import { prisma } from './lib/prisma'

async function main() {
  // Example: Fetch all records from a table
  // Replace 'user' with your actual model name
  const allUsers = await prisma.user.findMany()
  console.log('All users:', JSON.stringify(allUsers, null, 2))
}

main()
  .then(async () => {
    await prisma.$disconnect()
  })
  .catch(async (e) => {
    console.error(e)
    await prisma.$disconnect()
    process.exit(1)
  })
```

執行腳本:

```terminal
npx tsx script.ts
```

## 9. 演進您的 schema

要對資料庫結構進行變更:

### 9.1. 更新您的 Prisma schema 檔案

更新您的 Prisma schema 檔案以反映您想對資料庫結構進行的變更。例如,新增一個新模型:

```prisma file=prisma/schema.prisma
// add-start
model Post {
  id        Int      @id @default(autoincrement())
  title     String
  content   String?
  published Boolean  @default(false)
  authorId  Int
  author    User     @relation(fields: [authorId], references: [id])
}

model User {
  id    Int    @id @default(autoincrement())
  email String @unique
  name  String?
  posts Post[]
}
// add-end
```

### 9.2. 建立並套用遷移:

```terminal
npx prisma migrate dev --name your_migration_name
```

此指令將:
- 建立新的 SQL 遷移檔案
- 將遷移套用至您的資料庫
- 重新生成 Prisma Client
