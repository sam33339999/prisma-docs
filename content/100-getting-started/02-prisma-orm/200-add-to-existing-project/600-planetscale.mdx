[PlanetScale](https://planetscale.com) 是一個 serverless 資料庫平台。本指南涵蓋 **PlanetScale MySQL**,它建立在 Vitess 之上,提供資料庫分支、非阻塞的結構變更和自動備份。在本指南中,您將學習如何將 Prisma ORM 加入現有的 TypeScript 專案、將其連接至 PlanetScale MySQL、自檢現有的資料庫結構,並開始使用型別安全的 Prisma Client 進行查詢。

:::note

PlanetScale 也提供 PostgreSQL 資料庫。如果您使用的是 **PlanetScale PostgreSQL**,請改用[加入現有 PostgreSQL 專案指南](/getting-started/prisma-orm/add-to-existing-project/postgresql)。

:::

## 先決條件

<Prerequisites />

## 1. 設定 Prisma ORM

導航至您現有的專案目錄並安裝所需的相依套件:

```terminal
npm install prisma @types/node --save-dev
npm install @prisma/client @prisma/adapter-planetscale undici dotenv
```

以下是各個套件的功能:

- **`prisma`** - 用於執行 `prisma init`、`prisma db pull` 和 `prisma generate` 等指令的 Prisma CLI
- **`@prisma/client`** - 用於查詢資料庫的 Prisma Client 函式庫
- **`@prisma/adapter-planetscale`** - 將 Prisma Client 連接至資料庫的 PlanetScale 驅動程式適配器
- **`undici`** - PlanetScale 適配器所需的快速 HTTP/1.1 客戶端
- **`dotenv`** - 從 `.env` 檔案載入環境變數

## 2. 初始化 Prisma ORM

使用以下指令建立 [Prisma Schema](/orm/prisma-schema) 檔案來設定您的 Prisma ORM 專案:

```terminal
npx prisma init --datasource-provider mysql --output ../generated/prisma
```

此指令會執行以下幾項操作:

- 建立包含 `schema.prisma` 檔案的 `prisma/` 目錄,其中包含您的資料庫連線設定
- 在根目錄中建立用於環境變數的 `.env` 檔案
- 建立用於 Prisma 設定的 `prisma.config.ts` 檔案

生成的 `prisma.config.ts` 檔案如下所示:

```typescript file=prisma.config.ts
import 'dotenv/config'
import { defineConfig, env } from 'prisma/config'

export default defineConfig({
  schema: 'prisma/schema.prisma',
  migrations: {
    path: 'prisma/migrations',
  },
  datasource: {
    url: env('DATABASE_URL'),
  },
})
```

生成的 schema 使用[優先支援 ESM 的 `prisma-client` 生成器](/orm/prisma-schema/overview/generators#prisma-client)以及自訂輸出路徑:

```prisma file=prisma/schema.prisma
generator client {
  provider = "prisma-client"
  output   = "../generated/prisma"
}

datasource db {
  provider     = "mysql"
  relationMode = "prisma"
}
```

:::info

PlanetScale 需要 `relationMode = "prisma"`,因為它不支援外鍵約束。

:::

## 3. 連接您的資料庫

使用您的 PlanetScale 連線 URL 更新 `.env` 檔案:

```bash file=.env
DATABASE_URL="mysql://username:password@host.connect.psdb.cloud/mydb?sslaccept=strict"
```

您可以在 PlanetScale 儀表板中找到您的連線字串。

## 4. 自檢您的資料庫

執行以下指令來自檢您現有的資料庫:

```terminal
npx prisma db pull
```

此指令會讀取 `DATABASE_URL` 環境變數,連接至您的資料庫,並自檢資料庫結構。然後將資料庫結構從 SQL 轉換為 Prisma schema 中的資料模型。

![使用 Prisma ORM 自檢您的資料庫](/img/getting-started/prisma-db-pull-generate-schema.png)

自檢後,您的 Prisma schema 將包含代表現有資料庫資料表的模型。

## 5. 生成 Prisma ORM 型別

根據您自檢的 schema 生成 Prisma Client:

```terminal
npx prisma generate
```

這會在 `generated/prisma` 目錄中建立針對您資料庫結構量身打造的型別安全 Prisma Client。

## 6. 實例化 Prisma Client

建立一個工具檔案來實例化 Prisma Client。您需要將 Prisma ORM 的驅動程式適配器實例傳遞給 `PrismaClient` 建構函式:

```typescript file=lib/prisma.ts
import "dotenv/config";
import { PrismaPlanetScale } from '@prisma/adapter-planetscale'
import { PrismaClient } from '../generated/prisma/client'
import { fetch as undiciFetch } from 'undici'

const adapter = new PrismaPlanetScale({ url: process.env.DATABASE_URL, fetch: undiciFetch })
const prisma = new PrismaClient({ adapter })

export { prisma }
```

## 7. 查詢您的資料庫

現在您可以使用 Prisma Client 來查詢資料庫。建立一個 `script.ts` 檔案:

```typescript file=script.ts
import { prisma } from './lib/prisma'

async function main() {
  // Example: Fetch all records from a table
  // Replace 'user' with your actual model name
  const allUsers = await prisma.user.findMany()
  console.log('All users:', JSON.stringify(allUsers, null, 2))
}

main()
  .then(async () => {
    await prisma.$disconnect()
  })
  .catch(async (e) => {
    console.error(e)
    await prisma.$disconnect()
    process.exit(1)
  })
```

執行腳本:

```terminal
npx tsx script.ts
```

## 8. 演進您的 schema

PlanetScale 使用分支工作流程而非傳統的遷移。要對資料庫結構進行變更:

### 8.1. 更新您的 Prisma schema 檔案

更新您的 Prisma schema 檔案以反映您想對資料庫結構進行的變更。例如,新增一個新模型:

```prisma file=prisma/schema.prisma
// add-start
model Post {
  id        Int      @id @default(autoincrement())
  title     String
  content   String?
  published Boolean  @default(false)
  authorId  Int
  author    User     @relation(fields: [authorId], references: [id])
}

model User {
  id    Int    @id @default(autoincrement())
  email String @unique
  name  String?
  posts Post[]
}
// add-end
```

### 8.2. 將變更推送至您的開發分支:

```terminal
npx prisma db push
```

此指令將:
- 將 schema 變更套用至您的 PlanetScale 資料庫
- 重新生成 Prisma Client

:::info

對於正式環境部署,請使用 PlanetScale 的[分支工作流程](https://planetscale.com/docs/concepts/branching)來建立部署請求。

:::
