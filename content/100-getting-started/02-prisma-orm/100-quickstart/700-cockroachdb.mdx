[CockroachDB](https://www.cockroachlabs.com) 是一個為雲端應用程式打造的分散式 SQL 資料庫。在本指南中，您將學習如何從頭開始建立一個新的 TypeScript 專案，使用 Prisma ORM 連接到 CockroachDB，並生成一個 Prisma Client 以便輕鬆、型別安全地存取您的資料庫。

## 先決條件

<Prerequisites />

您還需要：

- 一個 [CockroachDB](https://www.cockroachlabs.com/) 資料庫
- 來自 CockroachDB 的資料庫連接字串

## 1. 建立新專案

<CreateProject />

## 2. 安裝所需的依賴套件

安裝本快速入門所需的套件：

```terminal
npm install prisma @types/node @types/pg --save-dev
npm install @prisma/client @prisma/adapter-pg pg dotenv
```

以下是每個套件的作用：

- **`prisma`** - Prisma CLI，用於執行 `prisma init`、`prisma migrate` 和 `prisma generate` 等命令
- **`@prisma/client`** - Prisma Client 函式庫，用於查詢您的資料庫
- **`@prisma/adapter-pg`** - [`node-postgres` 驅動程式配接器](/orm/overview/databases/postgresql#using-the-node-postgres-driver)，用於將 Prisma Client 連接到您的資料庫（CockroachDB 與 PostgreSQL 相容）
- **`pg`** - node-postgres 資料庫驅動程式
- **`@types/pg`** - node-postgres 的 TypeScript 型別定義
- **`dotenv`** - 從您的 `.env` 檔案載入環境變數

## 3. 設定 ESM 支援

更新 `tsconfig.json` 以支援 ESM 相容性：

```json file=tsconfig.json
{
  "compilerOptions": {
    "module": "ESNext",
    "moduleResolution": "node",
    "target": "ES2023",
    "strict": true,
    "esModuleInterop": true,
    "ignoreDeprecations": "6.0"
  }
}
```

更新 `package.json` 以啟用 ESM：

```json file=package.json
{
  // add-start
  "type": "module",
  // add-end
}
```

## 4. 初始化 Prisma ORM

您現在可以透過在 Prisma CLI 前面加上 `npx` 來呼叫它：

```terminal
npx prisma
```

接下來，使用以下命令建立您的 [Prisma Schema](/orm/prisma-schema) 檔案來設定您的 Prisma ORM 專案：

```terminal
npx prisma init --datasource-provider cockroachdb --output ../generated/prisma
```

此命令會執行以下操作：

- 建立一個 `prisma/` 目錄，其中包含一個 `schema.prisma` 檔案，內含您的資料庫連接和 schema 模型
- 在根目錄中建立一個 `.env` 檔案用於環境變數
- 建立一個 `prisma.config.ts` 檔案用於 Prisma 設定

生成的 `prisma.config.ts` 檔案如下所示：

```typescript file=prisma.config.ts
import 'dotenv/config'
import { defineConfig, env } from 'prisma/config'

export default defineConfig({
  schema: 'prisma/schema.prisma',
  migrations: {
    path: 'prisma/migrations',
  },
  datasource: {
    url: env('DATABASE_URL'),
  },
})
```

生成的 schema 使用 [ESM 優先的 `prisma-client` 生成器](/orm/prisma-schema/overview/generators#prisma-client)，並帶有自訂輸出路徑：

```prisma file=prisma/schema.prisma
generator client {
  provider = "prisma-client"
  output   = "../generated/prisma"
}

datasource db {
  provider = "cockroachdb"
}
```

使用您的 CockroachDB 連接字串更新您的 `.env` 檔案：

```env file=.env
DATABASE_URL="postgresql://username:password@host:26257/mydb?sslmode=require"
```

請將其替換為來自您的叢集儀表板的實際 CockroachDB 連接字串。

## 5. 定義您的資料模型

開啟 `prisma/schema.prisma` 並新增以下模型：

```prisma file=prisma/schema.prisma
generator client {
  provider = "prisma-client"
  output   = "../generated/prisma"
}

datasource db {
  provider = "cockroachdb"
}

//add-start
model User {
  id    Int     @id @default(autoincrement())
  email String  @unique
  name  String?
  posts Post[]
}

model Post {
  id        Int     @id @default(autoincrement())
  title     String
  content   String?
  published Boolean @default(false)
  author    User    @relation(fields: [authorId], references: [id])
  authorId  Int
}
//add-end
```

## 6. 建立並套用您的第一個遷移

建立您的第一個遷移以設定資料庫表格：

```terminal
npx prisma migrate dev --name init
```

此命令會根據您的 schema 建立資料庫表格。

現在執行以下命令來生成 Prisma Client：

```terminal
npx prisma generate
```

## 7. 實例化 Prisma Client

現在您已經安裝了所有依賴套件，可以實例化 Prisma Client。您需要將 Prisma ORM 的驅動程式配接器實例傳遞給 `PrismaClient` 建構函式：

```typescript file=lib/prisma.ts
import "dotenv/config";
import { PrismaPg } from '@prisma/adapter-pg'
import { PrismaClient } from '../generated/prisma/client'

const connectionString = `${process.env.DATABASE_URL}`

const adapter = new PrismaPg({ connectionString })
const prisma = new PrismaClient({ adapter })

export { prisma }
```

## 8. 撰寫您的第一個查詢

建立一個 `script.ts` 檔案來測試您的設定：

```typescript file=script.ts
import { prisma } from './lib/prisma'

async function main() {
  // Create a new user with a post
  const user = await prisma.user.create({
    data: {
      name: 'Alice',
      email: 'alice@prisma.io',
      posts: {
        create: {
          title: 'Hello World',
          content: 'This is my first post!',
          published: true,
        },
      },
    },
    include: {
      posts: true,
    },
  })
  console.log('Created user:', user)

  // Fetch all users with their posts
  const allUsers = await prisma.user.findMany({
    include: {
      posts: true,
    },
  })
  console.log('All users:', JSON.stringify(allUsers, null, 2))
}

main()
  .then(async () => {
    await prisma.$disconnect()
  })
  .catch(async (e) => {
    console.error(e)
    await prisma.$disconnect()
    process.exit(1)
  })
```

執行腳本：

```terminal
npx tsx script.ts
```

您應該會在控制台中看到已建立的使用者和所有使用者被印出！

## 9. 探索您的資料

探索 [CockroachDB](https://www.cockroachlabs.com/blog/cockroachdb-gui-options/) 建議的選項來查看和管理您的資料。

[Prisma Studio](/orm/tools/prisma-studio) 目前不支援 CockroachDB。支援可能會在未來版本中新增。詳情請參閱 [Prisma Studio 支援的資料庫](/orm/tools/prisma-studio#databases-supported-by-prisma-studio)。
