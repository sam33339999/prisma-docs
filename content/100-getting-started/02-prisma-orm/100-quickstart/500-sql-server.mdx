[Microsoft SQL Server](https://www.microsoft.com/en-us/sql-server) 是一個企業級的關聯式資料庫。在本指南中，您將學習如何從零開始設定新的 TypeScript 專案，使用 Prisma ORM 將其連接到 SQL Server，並產生 Prisma Client 以便輕鬆、型別安全地存取您的資料庫。

## 前置需求

<Prerequisites />

您還需要：

- 一個 [Microsoft SQL Server](https://learn.microsoft.com/en-us/sql/?view=sql-server-ver16) 資料庫
  - [在 Docker 上執行 Microsoft SQL Server](/orm/overview/databases/sql-server/sql-server-docker)
  - [在 Windows（本機）上執行 Microsoft SQL Server](/orm/overview/databases/sql-server/sql-server-local)
- 資料庫連線詳細資訊（主機、連接埠、使用者名稱、密碼、資料庫名稱）

## 1. 建立新專案

<CreateProject />

## 2. 安裝必要的相依套件

安裝此快速入門所需的套件：

```terminal
npm install prisma @types/node @types/mssql --save-dev
npm install @prisma/client @prisma/adapter-mssql dotenv
```

以下是各個套件的功能：

- **`prisma`** - Prisma CLI，用於執行 `prisma init`、`prisma migrate` 和 `prisma generate` 等命令
- **`@prisma/client`** - Prisma Client 函式庫，用於查詢您的資料庫
- **`@prisma/adapter-mssql`** - SQL Server 驅動程式適配器，將 Prisma Client 連接到您的資料庫
- **`@types/mssql`** - mssql 的 TypeScript 型別定義
- **`dotenv`** - 從您的 `.env` 檔案載入環境變數

## 3. 設定 ESM 支援

更新 `tsconfig.json` 以支援 ESM 相容性：

```json file=tsconfig.json
{
  "compilerOptions": {
    "module": "ESNext",
    "moduleResolution": "node",
    "target": "ES2023",
    "strict": true,
    "esModuleInterop": true,
    "ignoreDeprecations": "6.0"
  }
}
```

更新 `package.json` 以啟用 ESM：

```json file=package.json
{
  // add-start
  "type": "module",
  // add-end
}
```

## 4. 初始化 Prisma ORM

您現在可以透過在前面加上 `npx` 來呼叫 Prisma CLI：

```terminal
npx prisma
```

接下來，透過建立您的 [Prisma Schema](/orm/prisma-schema) 檔案來設定 Prisma ORM 專案，執行以下命令：

```terminal
npx prisma init --datasource-provider sqlserver --output ../generated/prisma
```

此命令會執行以下幾項操作：

- 建立一個 `prisma/` 目錄，其中包含 `schema.prisma` 檔案，該檔案包含您的資料庫連線和架構模型
- 在根目錄中建立一個 `.env` 檔案，用於存放環境變數
- 建立一個 `prisma.config.ts` 檔案，用於 Prisma 設定

產生的 `prisma.config.ts` 檔案如下所示：

```typescript file=prisma.config.ts
import 'dotenv/config'
import { defineConfig, env } from 'prisma/config'

export default defineConfig({
  schema: 'prisma/schema.prisma',
  migrations: {
    path: 'prisma/migrations',
  },
  datasource: {
    url: env('DATABASE_URL'),
  },
})
```

產生的 schema 使用[以 ESM 優先的 `prisma-client` 產生器](/orm/prisma-schema/overview/generators#prisma-client)，並具有自訂輸出路徑：

```prisma file=prisma/schema.prisma
generator client {
  provider = "prisma-client"
  output   = "../generated/prisma"
}

datasource db {
  provider = "sqlserver"
}
```

使用您的 SQL Server 連線字串詳細資訊更新您的 `.env` 檔案：

```env file=.env
DATABASE_URL="sqlserver://localhost:1433;database=mydb;user=username;password=password;encrypt=true"
//add-start
DB_USER="username"
DB_PASSWORD="password"
DB_NAME="mydb"
HOST="localhost"
//add-end
```

將佔位符替換為您實際的資料庫憑證：

- `localhost:1433`：您的 SQL Server 主機和連接埠
- `mydb`：您的資料庫名稱
- `username`：您的 SQL Server 使用者名稱
- `password`：您的 SQL Server 密碼

## 5. 定義您的資料模型

開啟 `prisma/schema.prisma` 並新增以下模型：

```prisma file=prisma/schema.prisma
generator client {
  provider = "prisma-client"
  output   = "../generated/prisma"
}

datasource db {
  provider = "sqlserver"
}

//add-start
model User {
  id    Int     @id @default(autoincrement())
  email String  @unique
  name  String?
  posts Post[]
}

model Post {
  id        Int     @id @default(autoincrement())
  title     String
  content   String?
  published Boolean @default(false)
  author    User    @relation(fields: [authorId], references: [id])
  authorId  Int
}
//add-end
```

## 6. 建立並套用您的第一個遷移

建立您的第一個遷移以設定資料庫表格：

```terminal
npx prisma migrate dev --name init
```

此命令會根據您的 schema 建立資料庫表格。

現在執行以下命令來產生 Prisma Client：

```terminal
npx prisma generate
```

## 7. 實例化 Prisma Client

現在您已經安裝了所有相依套件，可以實例化 Prisma Client。您需要將 Prisma ORM 的驅動程式適配器實例傳遞給 `PrismaClient` 建構函式：

```typescript file=lib/prisma.ts
import "dotenv/config";
import { PrismaMSSQL } from '@prisma/adapter-mssql';
import { PrismaClient } from '../generated/prisma/client';

const sqlConfig = {
  user: process.env.DB_USER,
  password: process.env.DB_PASSWORD,
  database: process.env.DB_NAME,
  server: process.env.HOST,
  pool: {
    max: 10,
    min: 0,
    idleTimeoutMillis: 30000
  },
  options: {
    encrypt: true, // for azure
    trustServerCertificate: false // change to true for local dev / self-signed certs
  }
}

const adapter = new PrismaMSSQL(sqlConfig)
const prisma = new PrismaClient({ adapter });

export { prisma }
```

## 8. 撰寫您的第一個查詢

建立一個 `script.ts` 檔案來測試您的設定：

```typescript file=script.ts
import { prisma } from './lib/prisma'

async function main() {
  // Create a new user with a post
  const user = await prisma.user.create({
    data: {
      name: 'Alice',
      email: 'alice@prisma.io',
      posts: {
        create: {
          title: 'Hello World',
          content: 'This is my first post!',
          published: true,
        },
      },
    },
    include: {
      posts: true,
    },
  })
  console.log('Created user:', user)

  // Fetch all users with their posts
  const allUsers = await prisma.user.findMany({
    include: {
      posts: true,
    },
  })
  console.log('All users:', JSON.stringify(allUsers, null, 2))
}

main()
  .then(async () => {
    await prisma.$disconnect()
  })
  .catch(async (e) => {
    console.error(e)
    await prisma.$disconnect()
    process.exit(1)
  })
```

執行腳本：

```terminal
npx tsx script.ts
```

您應該會在主控台看到已建立的使用者和所有使用者的資訊！
