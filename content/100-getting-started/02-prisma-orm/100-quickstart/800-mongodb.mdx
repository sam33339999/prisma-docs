[MongoDB](https://www.mongodb.com) 是一個流行的 NoSQL 文件資料庫。在本指南中，您將學習如何從頭開始建立一個新的 TypeScript 專案，使用 Prisma ORM 連接到 MongoDB，並生成一個 Prisma Client 以便輕鬆、型別安全地存取您的資料庫。

:::warning[Prisma ORM v7 的 MongoDB 支援]

**Prisma ORM v7 的 MongoDB 支援將在不久的將來推出。** 在此期間，在使用 MongoDB 時請使用 **Prisma ORM v6.19**（最新的 v6 版本）。

本指南使用 Prisma ORM v6.19 以確保與 MongoDB 完全相容。

:::

## 先決條件

- 您的系統已安裝 Node.js [並符合支援的版本](/orm/more/upgrade-guides/upgrading-versions/upgrading-to-prisma-6#minimum-supported-nodejs-versions)
- 一個可透過連接字串存取的 [MongoDB](https://www.mongodb.com/) 資料庫

## 2. 安裝所需的依賴套件

安裝本快速入門所需的套件：

```terminal
npm install prisma@6.19 @types/node --save-dev
npm install @prisma/client@6.19 dotenv
```

:::info[為什麼使用 Prisma v6.19？]

這是 Prisma ORM v6 的最新穩定版本，完全支援 MongoDB。Prisma ORM v7 的 MongoDB 支援即將推出。

您也可以安裝 `prisma@6` 和 `@prisma/client@6` 以自動取得最新的 v6 版本。

:::

以下是每個套件的作用：

- **`prisma`** - Prisma CLI，用於執行 `prisma init`、`prisma db push` 和 `prisma generate` 等命令
- **`@prisma/client`** - Prisma Client 函式庫，用於查詢您的資料庫
- **`dotenv`** - 從您的 `.env` 檔案載入環境變數

:::note

MongoDB 不需要驅動程式配接器，因為 Prisma ORM 直接連接到 MongoDB。

:::

## 3. 設定 ESM 支援

更新 `tsconfig.json` 以支援 ESM 相容性：

```json file=tsconfig.json
{
  "compilerOptions": {
    "module": "ESNext",
    "moduleResolution": "node",
    "target": "ES2023",
    "strict": true,
    "esModuleInterop": true,
    "ignoreDeprecations": "6.0"
  }
}
```

更新 `package.json` 以啟用 ESM：

```json file=package.json
{
  // add-start
  "type": "module",
  // add-end
}
```

## 4. 初始化 Prisma ORM

您現在可以透過在 Prisma CLI 前面加上 `npx` 來呼叫它：

```terminal
npx prisma
```

接下來，使用以下命令建立您的 [Prisma Schema](/orm/prisma-schema) 檔案來設定您的 Prisma ORM 專案：

```terminal
npx prisma init --datasource-provider mongodb --output ../generated/prisma
```

此命令會執行以下操作：

- 建立一個 `prisma/` 目錄，其中包含一個 `schema.prisma` 檔案，用於您的資料庫連接和 schema 模型
- 在根目錄中建立一個 `.env` 檔案用於環境變數
- 建立一個 `prisma.config.ts` 檔案用於 Prisma 設定

:::note

當您在本指南稍後執行 `npx prisma generate` 時，Prisma Client 將會在 `generated/prisma/` 目錄中生成。

:::

生成的 `prisma.config.ts` 檔案如下所示：

```typescript file=prisma.config.ts
import { defineConfig, env } from 'prisma/config'

export default defineConfig({
  schema: 'prisma/schema.prisma',
  migrations: {
    path: 'prisma/migrations',
  },
  engine: "classic",
  datasource: {
    url: env('DATABASE_URL'),
  },
})
```

在 `prisma.config.ts` 中新增 `dotenv`，以便 Prisma 可以從您的 `.env` 檔案載入環境變數：

```typescript file=prisma.config.ts
// add-start
import 'dotenv/config'
// add-end
import { defineConfig, env } from 'prisma/config'

export default defineConfig({
  schema: 'prisma/schema.prisma',
  migrations: {
    path: 'prisma/migrations',
  },
  engine: "classic",
  datasource: {
    url: env('DATABASE_URL'),
  },
})
```

生成的 schema 使用 [ESM 優先的 `prisma-client` 生成器](/orm/prisma-schema/overview/generators#prisma-client)，並帶有自訂輸出路徑：

```prisma file=prisma/schema.prisma
generator client {
  provider = "prisma-client"
  output   = "../generated/prisma"
}

datasource db {
  provider = "mongodb"
  url = env("DATABASE_URL")
}
```

使用您的 MongoDB 連接字串更新您的 `.env` 檔案：

```env file=.env
DATABASE_URL="mongodb+srv://username:password@cluster.mongodb.net/mydb"
```

:::tip

請將 `username`、`password`、`cluster` 和 `mydb` 替換為您實際的 MongoDB 憑證和資料庫名稱。您可以從 [MongoDB Atlas](https://www.mongodb.com/cloud/atlas) 或您的 MongoDB 部署中取得連接字串。

:::

## 5. 定義您的資料模型

開啟 `prisma/schema.prisma` 並新增以下模型：

```prisma file=prisma/schema.prisma
generator client {
  provider = "prisma-client"
  output   = "../generated/prisma"
}

datasource db {
  provider = "mongodb"
  url = env("DATABASE_URL")
}

//add-start
model User {
  id    String  @id @default(auto()) @map("_id") @db.ObjectId
  email String  @unique
  name  String?
  posts Post[]
}

model Post {
  id        String  @id @default(auto()) @map("_id") @db.ObjectId
  title     String
  content   String?
  published Boolean @default(false)
  author    User    @relation(fields: [authorId], references: [id])
  authorId  String  @db.ObjectId
}
//add-end
```

## 6. 將您的 schema 推送到 MongoDB

MongoDB 不像關聯式資料庫那樣支援遷移。相反地，使用 `db push` 來同步您的 schema：

```terminal
npx prisma db push
```

此命令會：
- 根據您的 schema 在 MongoDB 中建立集合
- 自動生成 Prisma Client

:::info

與關聯式資料庫不同，MongoDB 使用彈性的 schema。`db push` 命令確保您的 Prisma schema 反映在您的資料庫中，而不會建立遷移檔案。

:::

## 7. 實例化 Prisma Client

現在您已經安裝了所有依賴套件，可以實例化 Prisma Client：

```typescript file=lib/prisma.ts
import "dotenv/config";
import { PrismaClient } from '../generated/prisma/client'

const prisma = new PrismaClient()

export { prisma }
```

## 8. 撰寫您的第一個查詢

建立一個 `script.ts` 檔案來測試您的設定：

```typescript file=script.ts
import { prisma } from './lib/prisma'

async function main() {
  // Create a new user with a post
  const user = await prisma.user.create({
    data: {
      name: 'Alice',
      email: 'alice@prisma.io',
      posts: {
        create: {
          title: 'Hello World',
          content: 'This is my first post!',
          published: true,
        },
      },
    },
    include: {
      posts: true,
    },
  })
  console.log('Created user:', user)

  // Fetch all users with their posts
  const allUsers = await prisma.user.findMany({
    include: {
      posts: true,
    },
  })
  console.log('All users:', JSON.stringify(allUsers, null, 2))
}

main()
  .then(async () => {
    await prisma.$disconnect()
  })
  .catch(async (e) => {
    console.error(e)
    await prisma.$disconnect()
    process.exit(1)
  })
```

執行腳本：

```terminal
npx tsx script.ts
```

您應該會在控制台中看到已建立的使用者和所有使用者被印出！

## 9. 探索您的資料

您可以使用 [MongoDB Atlas](https://www.mongodb.com/cloud/atlas)、MongoDB shell 或 MongoDB Compass 來查看和管理您的資料。

[Prisma Studio](/orm/tools/prisma-studio) 目前不支援 MongoDB。支援可能會在未來版本中新增。詳情請參閱 [Prisma Studio 支援的資料庫](/orm/tools/prisma-studio#databases-supported-by-prisma-studio)。

## 疑難排解

### `Error in connector: SCRAM failure: Authentication failed.`

如果您看到 `Error in connector: SCRAM failure: Authentication failed.` 錯誤訊息，您可以透過在連接字串末尾[新增](https://github.com/prisma/prisma/discussions/9994#discussioncomment-1562283) `?authSource=admin` 來指定用於驗證的來源資料庫。

### `Raw query failed. Error code 8000 (AtlasError): empty database name not allowed.`

如果您看到 `Raw query failed. Code: unknown. Message: Kind: Command failed: Error code 8000 (AtlasError): empty database name not allowed.` 錯誤訊息，請務必在資料庫 URL 中附加資料庫名稱。您可以在此 [GitHub issue](https://github.com/prisma/docs/issues/5562) 中找到更多資訊。
