[SQLite](https://sqlite.org) 是一個輕量級、基於檔案的資料庫，非常適合開發、原型設計和小型應用程式。它不需要設定，並將資料儲存在本地檔案中。

在本指南中，你將學習如何從頭設定新的 TypeScript 專案、使用 Prisma ORM 將其連接到 SQLite，並產生 Prisma Client 以便輕鬆、型別安全地存取你的資料庫。

## 2. 安裝所需的相依套件

安裝此快速入門所需的套件：

```terminal
npm install prisma @types/node @types/better-sqlite3 --save-dev
npm install @prisma/client @prisma/adapter-better-sqlite3 dotenv
```

:::note[使用 SQLite 的 pnpm 使用者]
如果使用 pnpm 10+ 和 `pnpx`，在執行 Prisma Studio 時，由於 SQLite 的原生相依需求，你需要使用 [`--allow-build=better-sqlite3`](https://pnpm.io/cli/dlx#--allow-build) 旗標。
:::

以下是每個套件的功能：

- **`prisma`** - Prisma CLI，用於執行 `prisma init`、`prisma migrate` 和 `prisma generate` 等指令
- **`@prisma/client`** - Prisma Client 函式庫，用於查詢你的資料庫
- **`@prisma/adapter-better-sqlite3`** - SQLite 驅動程式轉接器，將 Prisma Client 連接到你的資料庫
- **`@types/better-sqlite3`** - better-sqlite3 的 TypeScript 型別定義
- **`dotenv`** - 從你的 `.env` 檔案載入環境變數

## 3. 設定 ESM 支援

更新 `tsconfig.json` 以支援 ESM 相容性：

```json file=tsconfig.json
{
  "compilerOptions": {
    "module": "ESNext",
    "moduleResolution": "node",
    "target": "ES2023",
    "strict": true,
    "esModuleInterop": true,
    "ignoreDeprecations": "6.0"
  }
}
```

更新 `package.json` 以啟用 ESM：

```json file=package.json
{
  // add-start
  "type": "module",
  // add-end
}
```

## 4. 初始化 Prisma ORM

現在你可以透過在前面加上 `npx` 來呼叫 Prisma CLI：

```terminal
npx prisma
```

接下來，使用以下指令建立你的 [Prisma Schema](/orm/prisma-schema) 檔案來設定你的 Prisma ORM 專案：

```terminal
npx prisma init --datasource-provider sqlite --output ../generated/prisma
```

此指令會執行以下幾件事：

- 建立一個 `prisma/` 目錄，其中包含一個 `schema.prisma` 檔案，內含你的資料庫連線和 schema 模型
- 在根目錄中建立一個 `.env` 檔案用於環境變數
- 建立一個 `prisma.config.ts` 檔案用於 Prisma 設定

產生的 `prisma.config.ts` 檔案如下所示：

```typescript file=prisma.config.ts
import 'dotenv/config'
import { defineConfig, env } from 'prisma/config'

export default defineConfig({
  schema: 'prisma/schema.prisma',
  migrations: {
    path: 'prisma/migrations',
  },
  datasource: {
    url: env('DATABASE_URL'),
  },
})
```

產生的 schema 使用 [ESM 優先的 `prisma-client` 產生器](/orm/prisma-schema/overview/generators#prisma-client)以及自訂的輸出路徑：

```prisma file=prisma/schema.prisma
generator client {
  provider = "prisma-client"
  output   = "../generated/prisma"
}

datasource db {
  provider = "sqlite"
}
```

應該會建立一個包含以下值的 `.env` 檔案：

```env file=.env
DATABASE_URL="file:./dev.db"
```

## 5. 定義你的資料模型

開啟 `prisma/schema.prisma` 並新增以下模型：

```prisma file=prisma/schema.prisma
generator client {
  provider = "prisma-client"
  output   = "../generated/prisma"
}

datasource db {
  provider = "sqlite"
}

//add-start
model User {
  id    Int     @id @default(autoincrement())
  email String  @unique
  name  String?
  posts Post[]
}

model Post {
  id        Int     @id @default(autoincrement())
  title     String
  content   String?
  published Boolean @default(false)
  author    User    @relation(fields: [authorId], references: [id])
  authorId  Int
}
//add-end
```

## 6. 建立並套用你的第一個遷移

建立你的第一個遷移以設定資料庫表格：

```terminal
npx prisma migrate dev --name init
```

此指令會根據你的 schema 建立資料庫表格。

現在執行以下指令來產生 Prisma Client：

```terminal
npx prisma generate
```

## 7. 實例化 Prisma Client

現在你已經安裝了所有相依套件，可以實例化 Prisma Client 了。你需要將 Prisma ORM 的驅動程式轉接器實例傳遞給 `PrismaClient` 建構函式：

```typescript file=lib/prisma.ts
import "dotenv/config";
import { PrismaBetterSqlite3 } from "@prisma/adapter-better-sqlite3";
import { PrismaClient } from "../generated/prisma/client";

const connectionString = `${process.env.DATABASE_URL}`;

const adapter = new PrismaBetterSqlite3({ url: connectionString });
const prisma = new PrismaClient({ adapter });

export { prisma };
```

:::tip 在 Bun 中使用 SQLite
當以 Bun 為目標時，請使用 `@prisma/adapter-libsql` 轉接器，而不是 `@prisma/adapter-better-sqlite3`。Bun 不支援 `better-sqlite3` 所依賴的原生 SQLite 驅動程式（請參閱 [`node:sqlite` 參考文件](https://bun.com/reference/node/sqlite)）。像這樣實例化 Prisma Client：

```ts
import 'dotenv/config';
import { PrismaLibSql } from '@prisma/adapter-libsql';
import { PrismaClient } from '../generated/prisma/client';

const adapter = new PrismaLibSql({
  url: process.env.DATABASE_URL ?? '',
});

const prisma = new PrismaClient({ adapter });

export { prisma };
```
:::

## 8. 撰寫你的第一個查詢

建立一個 `script.ts` 檔案來測試你的設定：

```typescript file=script.ts
import { prisma } from './lib/prisma'

async function main() {
  // Create a new user with a post
  const user = await prisma.user.create({
    data: {
      name: 'Alice',
      email: 'alice@prisma.io',
      posts: {
        create: {
          title: 'Hello World',
          content: 'This is my first post!',
          published: true,
        },
      },
    },
    include: {
      posts: true,
    },
  })
  console.log('Created user:', user)

  // Fetch all users with their posts
  const allUsers = await prisma.user.findMany({
    include: {
      posts: true,
    },
  })
  console.log('All users:', JSON.stringify(allUsers, null, 2))
}

main()
  .then(async () => {
    await prisma.$disconnect()
  })
  .catch(async (e) => {
    console.error(e)
    await prisma.$disconnect()
    process.exit(1)
  })
```

執行腳本：

```terminal
npx tsx script.ts
```

你應該會看到建立的使用者和所有使用者列印到主控台！

## 9. 使用 Prisma Studio 探索你的資料

<ExploreData />

:::note[Prisma Studio 的 SQLite 需求]
- SQLite 的資料庫 URL 中，檔案路徑目前必須具有 `file:` 協定
- **Node.js 22.5+**：使用內建的 `node:sqlite` 模組即可立即運作
  - 可能需要 `NODE_OPTIONS=--experimental-sqlite` 環境變數
- **Node.js 20**：需要安裝 `better-sqlite3` 作為相依套件
  - 如果使用 pnpm 10+ 和 `pnpx`，你需要使用 [`--allow-build=better-sqlite3`](https://pnpm.io/cli/dlx#--allow-build) 旗標
- **Deno >= 2.2**：透過[內建的 SQLite 模組](https://docs.deno.com/api/node/sqlite/)支援
- **Bun**：Prisma Studio 的 SQLite 支援即將推出，目前尚未提供

:::tip[在 `better-sqlite3` 中使用 `npx`]

如果你的運行時環境中沒有 `node:sqlite`，或者不想將 `better-sqlite3` 安裝為硬性相依套件（它會增加約 10MB），你可以使用 `npx` 臨時安裝所需的套件：

```terminal
npx -p better-sqlite3 -p prisma prisma studio --url file:./dev.db
```

此指令會：
- 臨時安裝 `better-sqlite3`，而不將其加入你的專案相依套件
- 使用指定的 SQLite 資料庫檔案執行 Prisma Studio
- 避免專案中 `better-sqlite3` 的 10MB 額外負擔

:::
