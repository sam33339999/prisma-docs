[Prisma Postgres](/postgres) 是一個完全託管的 PostgreSQL 資料庫，可以縮放至零並與 Prisma ORM 和 Prisma Studio 順暢整合。在本指南中，你將學習如何從頭設定新的 TypeScript 專案、使用 Prisma ORM 將其連接到 Prisma Postgres，並產生 Prisma Client 以便輕鬆、型別安全地存取你的資料庫。

## 2. 安裝所需的相依套件

安裝此快速入門所需的套件：

```terminal
npm install prisma @types/node @types/pg --save-dev
npm install @prisma/client @prisma/adapter-pg pg dotenv
```

以下是每個套件的功能：

- **`prisma`** - Prisma CLI，用於執行 `prisma init`、`prisma migrate` 和 `prisma generate` 等指令
- **`@prisma/client`** - Prisma Client 函式庫，用於查詢你的資料庫
- **`@prisma/adapter-pg`** - [`node-postgres` 驅動程式轉接器](/orm/overview/databases/postgresql#using-the-node-postgres-driver)，將 Prisma Client 連接到你的資料庫
- **`pg`** - node-postgres 資料庫驅動程式
- **`@types/pg`** - node-postgres 的 TypeScript 型別定義
- **`dotenv`** - 從你的 `.env` 檔案載入環境變數

## 3. 設定 ESM 支援

更新 `tsconfig.json` 以支援 ESM 相容性：

```json file=tsconfig.json
{
  "compilerOptions": {
    "module": "ESNext",
    "moduleResolution": "node",
    "target": "ES2023",
    "strict": true,
    "esModuleInterop": true,
    "ignoreDeprecations": "6.0"
  }
}
```

更新 `package.json` 以啟用 ESM：

```json file=package.json
{
  // add-start
  "type": "module",
  // add-end
}
```

## 4. 初始化 Prisma ORM 並建立 Prisma Postgres 資料庫

現在你可以透過在前面加上 `npx` 來呼叫 Prisma CLI：

```terminal
npx prisma
```

接下來，使用以下指令建立你的 [Prisma Schema](/orm/prisma-schema) 檔案來設定你的 Prisma ORM 專案：

```terminal
npx prisma init --db --output ../generated/prisma
```

:::info

在設定 Prisma Postgres 資料庫時，你需要回答幾個問題。選擇最接近你所在位置的區域以及一個容易記住的資料庫名稱。

:::

此指令會執行以下幾件事：

- 建立一個 `prisma/` 目錄，其中包含一個 `schema.prisma` 檔案，內含你的資料庫連線和 schema 模型
- 建立一個新的 Prisma Postgres 資料庫（使用 `--db` 旗標時）
- 在根目錄中建立一個 `.env` 檔案用於環境變數
- 建立一個 `prisma.config.ts` 檔案用於 Prisma 設定

產生的 `prisma.config.ts` 檔案如下所示：

```typescript file=prisma.config.ts
import 'dotenv/config'
import { defineConfig, env } from 'prisma/config'

export default defineConfig({
  schema: 'prisma/schema.prisma',
  migrations: {
    path: 'prisma/migrations',
  },
  datasource: {
    url: env('DATABASE_URL'),
  },
})
```

產生的 schema 使用 [ESM 優先的 `prisma-client` 產生器](/orm/prisma-schema/overview/generators#prisma-client)以及自訂的輸出路徑：

```prisma file=prisma/schema.prisma
generator client {
  provider = "prisma-client"
  output   = "../generated/prisma"
}

datasource db {
  provider = "postgresql"
}
```

## 5. 定義你的資料模型

開啟 `prisma/schema.prisma` 並新增以下模型：

```prisma file=prisma/schema.prisma
generator client {
  provider = "prisma-client"
  output   = "../generated/prisma"
}

datasource db {
  provider = "postgresql"
}

//add-start
model User {
  id    Int     @id @default(autoincrement())
  email String  @unique
  name  String?
  posts Post[]
}

model Post {
  id        Int     @id @default(autoincrement())
  title     String
  content   String?
  published Boolean @default(false)
  author    User    @relation(fields: [authorId], references: [id])
  authorId  Int
}
//add-end
```

## 6. 建立並套用你的第一個遷移

建立你的第一個遷移以設定資料庫表格：

```terminal
npx prisma migrate dev --name init
```

此指令會根據你的 schema 建立資料庫表格。

現在執行以下指令來產生 Prisma Client：

```terminal
npx prisma generate
```

## 7. 實例化 Prisma Client

現在你已經安裝了所有相依套件，可以實例化 Prisma Client 了。你需要將 Prisma ORM 的驅動程式轉接器實例傳遞給 `PrismaClient` 建構函式：

```typescript file=lib/prisma.ts
import "dotenv/config";
import { PrismaPg } from '@prisma/adapter-pg'
import { PrismaClient } from '../generated/prisma/client'

const connectionString = `${process.env.DATABASE_URL}`

const adapter = new PrismaPg({ connectionString })
const prisma = new PrismaClient({ adapter })

export { prisma }
```

:::tip

如果你需要從邊緣運行時環境（Cloudflare Workers、Vercel Edge Functions 等）透過 HTTP 查詢你的資料庫，請使用 [Prisma Postgres serverless 驅動程式](/postgres/database/serverless-driver#use-with-prisma-orm)。

:::

## 8. 撰寫你的第一個查詢

建立一個 `script.ts` 檔案來測試你的設定：

```typescript file=script.ts
import { prisma } from './lib/prisma'

async function main() {
  // Create a new user with a post
  const user = await prisma.user.create({
    data: {
      name: 'Alice',
      email: 'alice@prisma.io',
      posts: {
        create: {
          title: 'Hello World',
          content: 'This is my first post!',
          published: true,
        },
      },
    },
    include: {
      posts: true,
    },
  })
  console.log('Created user:', user)

  // Fetch all users with their posts
  const allUsers = await prisma.user.findMany({
    include: {
      posts: true,
    },
  })
  console.log('All users:', JSON.stringify(allUsers, null, 2))
}

main()
  .then(async () => {
    await prisma.$disconnect()
  })
  .catch(async (e) => {
    console.error(e)
    await prisma.$disconnect()
    process.exit(1)
  })
```

執行腳本：

```terminal
npx tsx script.ts
```

你應該會看到建立的使用者和所有使用者列印到主控台！
