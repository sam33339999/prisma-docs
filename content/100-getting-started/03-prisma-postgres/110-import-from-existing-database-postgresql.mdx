本指南提供了從現有 PostgreSQL 資料庫匯入資料到 Prisma Postgres 的逐步說明。

您可以透過三個步驟完成此遷移:

1. 建立一個新的 Prisma Postgres 資料庫。
1. 透過 `pg_dump` 匯出現有資料。
1. 透過 `pg_restore` 將先前匯出的資料匯入到 Prisma Postgres。

在第三步中,您將使用[直接連接](/postgres/database/direct-connections)安全地連接到您的 Prisma Postgres 資料庫以執行 `pg_restore`。

## 先決條件

- 現有 PostgreSQL 資料庫的連接 URL
- [Prisma Data Platform](https://console.prisma.io) 帳戶
- 已安裝 Node.js 18+
- 用於建立和還原備份的 PostgreSQL CLI 工具(`pg_dump`、`pg_restore`)

:::info[確保您的 PostgreSQL 工具與 Prisma Postgres 版本匹配]

Prisma Postgres 執行 PostgreSQL 17。您的 `pg_dump` 和 `pg_restore` 工具需要是版本 17 以確保相容性。您可以透過執行 `pg_dump --version` 或 `pg_restore --version` 來檢查您的版本。

:::

## 1. 建立新的 Prisma Postgres 資料庫

按照以下步驟建立新的 Prisma Postgres 資料庫:

1. 登入 [Prisma Data Platform](https://console.prisma.io/) 並開啟 Console。
1. 在您選擇的[工作區](/platform/about#workspace)中,點擊 **New project** 按鈕。
1. 在 **Name** 欄位中輸入專案名稱,例如 **hello-ppg**。
1. 在 **Prisma Postgres** 部分,點擊 **Get started** 按鈕。
1. 在 **Region** 下拉式選單中,選擇最接近您當前位置的地區,例如 **US East (N. Virginia)**。
1. 點擊 **Create project** 按鈕。

資料庫佈建完成後,取得您的直接連接字串:

1. 導航到您的活動 Prisma Postgres 實例。
1. 點擊專案側邊欄中的 **API Keys** 分頁。
1. 點擊 **Create API key** 按鈕。
1. 在彈出視窗中,為 API 金鑰提供 **Name** 並點擊 **Create**。
1. 複製以 `postgres://` 開頭的連接字串,這是您的直接連接字串。

儲存連接字串,您將在步驟 3 中使用它。

## 2. 從現有資料庫匯出資料

在此步驟中,您將從現有資料庫匯出資料並將其儲存在本地機器上的 `.bak` 檔案中。

確保準備好現有資料庫的連接 URL,它應該[結構化](/orm/overview/databases/postgresql#connection-url)如下:

```no-copy
postgresql://USER:PASSWORD@HOST:PORT/DATABASE
```

展開以下內容以獲取特定提供者的說明,幫助您確定正確的連接字串:

<details>
<summary>Neon</summary>

<br />

- 確保透過關閉 **Connection pooling** 切換開關來選擇非池化連接字串。
- `sslmode` 必須設定為 `require` 並附加到您的 Neon 資料庫 url 以使命令正常運作。
- 連接 URL 應類似於:
    ```no-copy
    postgresql://USER:PASSWORD@YOUR-NEON-HOST/DATABASE?sslmode=require
    ```

</details>

<details>
<summary>Supabase</summary>

- 使用[Supavisor session mode](https://supabase.com/docs/guides/database/connecting-to-postgres#supavisor-session-mode)的資料庫連接 URL。
- 連接 URL 應類似於:
    ```no-copy
    postgres://postgres.apbkobhfnmcqqzqeeqss:[YOUR-PASSWORD]@aws-0-ca-central-1.pooler.supabase.com:5432/postgres
    ```

</details>

接下來,執行以下命令來匯出 PostgreSQL 資料庫的資料(將 `__DATABASE_URL__` 佔位符替換為您的實際資料庫連接 URL):

```terminal
pg_dump \
  -Fc \
  -v \
  -d __DATABASE_URL__ \
  -n public \
  -f db_dump.bak
```

以下是此命令使用的 CLI 選項的快速概述:

- `-Fc`: 使用自訂格式進行備份,建議用於 `pg_restore`
- `-v`: 在詳細模式下執行 `pg_dump`
- `-d`: 指定資料庫連接字串
- `-n`: 指定目標 PostgreSQL schema
- `-f`: 指定備份檔案的輸出名稱

執行此命令將建立一個名為 `db_dump.bak` 的備份檔案,您將在下一步中使用它來將資料還原到您的 Prisma Postgres 資料庫。

## 3. 將資料匯入 Prisma Postgres

在本節中,您將使用[直接連接字串](/postgres/database/direct-connections)連接到您的 Prisma Postgres 實例並透過 `pg_restore` 匯入資料。

您在步驟 1 中的直接連接字串應該如下所示:

```no-copy
postgres://USER:PASSWORD@db.prisma.io:5432/?sslmode=require
```

使用**步驟 2** 中的備份檔案透過執行此命令使用 `pg_restore` 將資料還原到您的 Prisma Postgres 資料庫(將 `__USER__`、`__PASSWORD__` 替換為您直接連接字串中的值):

```bash
pg_restore \
  -h db.prisma.io \
  -p 5432 \
  -U __USER__ \
  -d postgres \
  -v \
  ./db_dump.bak \
&& echo "-complete-"
```

當提示時,輸入您直接連接字串中的 `__PASSWORD__`。

:::tip

您也可以使用完整的連接字串格式:

```bash
pg_restore \
  -d "postgres://USER:PASSWORD@db.prisma.io:5432/postgres?sslmode=require" \
  -v \
  ./db_dump.bak \
&& echo "-complete-"
```

:::

命令執行完成後,您將成功地從現有 PostgreSQL 資料庫匯入資料到 Prisma Postgres 🎉

要驗證匯入是否成功,您可以使用 [Prisma Studio](/postgres/integrations/viewing-data#viewing-and-editing-data-in-prisma-studio)。您可以在專案的左側邊欄中點擊 **Studio** 分頁在 [Platform Console](https://console.prisma.io) 中開啟它,或執行此命令在本地啟動 Prisma Studio:

```terminal
npx prisma studio
```

## 4. 更新應用程式程式碼以查詢 Prisma Postgres

### 情境 A:您已經在使用 Prisma ORM

如果您已經在使用 Prisma ORM,您需要更新資料庫連接 URL 以指向您的新 Prisma Postgres 實例。

更新 `.env` 檔案中的 `DATABASE_URL` 以匹配步驟 1 中的 Prisma Postgres 直接連接字串:

```bash file=.env
DATABASE_URL="postgres://USER:PASSWORD@db.prisma.io:5432/?sslmode=require"
```

然後,重新生成 Prisma Client 以使更新的環境變數生效:

```terminal
npx prisma generate
```

完成後,您可以執行應用程式,它應該像以前一樣運作。

:::tip

要獲取從頭開始使用 Prisma ORM 和 Prisma Postgres 的完整指南,包括驅動程式適配器配置和最佳實踐,請參閱 [Prisma ORM 與 Prisma Postgres 快速入門](/getting-started/prisma-orm/quickstart/prisma-postgres)。

:::

### 情境 B:您尚未使用 Prisma ORM

如果您尚未使用 Prisma ORM,您需要完成以下步驟才能從應用程式使用 Prisma Postgres:

1. 在專案中安裝 Prisma CLI 和其他所需的依賴項
1. 內省資料庫以生成 Prisma schema
1. 生成 Prisma Client
1. 更新應用程式中的查詢以使用 Prisma ORM

您可以在本指南中找到此過程的詳細逐步說明:[將 Prisma ORM 新增到現有專案](/getting-started/prisma-orm/add-to-existing-project/prisma-postgres)。
