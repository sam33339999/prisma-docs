本指南提供了從現有 MySQL 資料庫匯入資料到 Prisma Postgres 的逐步說明。

您可以透過四個步驟完成此遷移:

1. 建立一個新的 Prisma Postgres 資料庫。
1. 使用[直接連接](/postgres/database/direct-connections)直接連接到 Prisma Postgres 實例。
1. 使用 [pgloader](https://pgloader.io/) 將您的 MySQL 資料遷移到 Prisma Postgres。
1. 為 Prisma Postgres 配置您的 Prisma 專案。

## 先決條件

- 現有 MySQL 資料庫的連接 URL。
- [Prisma Data Platform](https://console.prisma.io) 帳戶。
- 已安裝 Node.js 18+。
- 已安裝 [pgloader](https://pgloader.io/)。

:::info[確保您的 PostgreSQL 工具與 Prisma Postgres 版本匹配]

Prisma Postgres 執行 PostgreSQL 17。您使用的 `pgloader` 和任何其他 PostgreSQL 工具需要與 PostgreSQL 17 相容。

:::

我們建議在單獨的 git 開發分支中嘗試此遷移。

## 1. 建立新的 Prisma Postgres 資料庫

按照以下步驟建立新的 Prisma Postgres 資料庫:

1. 登入 [Prisma Data Platform](https://console.prisma.io/) 並開啟 Console。
1. 在您選擇的[工作區](/platform/about#workspace)中,點擊 **New project** 按鈕。
1. 在 **Name** 欄位中輸入專案名稱,例如 **hello-ppg**。
1. 在 **Prisma Postgres** 部分,點擊 **Get started** 按鈕。
1. 在 **Region** 下拉式選單中,選擇最接近您當前位置的地區,例如 **US East (N. Virginia)**。
1. 點擊 **Create project** 按鈕。

資料庫佈建完成後,找到您的直接 Prisma Postgres 連接字串:

1. 導航到您的活動 Prisma Postgres 實例。
1. 點擊專案側邊欄中的 **API Keys** 分頁。
1. 點擊 **Create API key** 按鈕。
1. 在彈出視窗中,為 API 金鑰提供 **Name** 並點擊 **Create**。
1. 複製以 `postgres://` 開頭的連接字串,這是您的直接連接字串。

儲存連接字串,您將在下一步中使用它。

## 2. 準備您的直接連接字串

在此步驟中,您將使用在步驟 1 中取得的[直接連接字串](/postgres/database/direct-connections)連接到您的 Prisma Postgres 實例。

您的直接連接字串應該如下所示:

```no-copy
postgres://USER:PASSWORD@db.prisma.io:5432/?sslmode=require
```

您將在下一步配置 pgloader 時使用此連接字串。


## 3. 使用 pgloader 將您的 MySQL 資料遷移到 Prisma Postgres

現在您已經有了到 Prisma Postgres 實例的活動連接,您將使用 [pgloader](https://pgloader.io/) 將資料從 MySQL 資料庫匯出到 Prisma Postgres。

開啟一個單獨的終端視窗並建立一個 `config.load` 檔案:

```terminal
touch config.load
```

在您偏好的文字編輯器中開啟 `config.load` 檔案並複製貼上以下配置:

```text file=config.load
LOAD DATABASE
    FROM mysql://username:password@host:PORT/database_name
    INTO postgres://__USER__:__PASSWORD__@db.prisma.io:5432/?sslmode=require

WITH quote identifiers,    -- preserve table/column name case by quoting them
     include drop,
     create tables,
     create indexes,
     reset sequences

ALTER SCHEMA 'database_name' RENAME TO 'public';
```

確保在 `config.load` 檔案中更新以下詳細資訊:

- `FROM` url (MySQL 資料庫 URL):
  - 將 `username`、`password`、`host`、`PORT` 和 `database_name` 替換為您 MySQL 資料庫的實際連接詳細資訊。
  - 確保您的連接字串包含 `useSSL=true`(如果需要 SSL),例如:`mysql://username:password@host:PORT/database_name?useSSL=true`。請注意,使用 PlanetScale 時,附加 `sslaccept=strict` 將無法運作。
- `INTO` url (Postgres 資料庫 URL):
  - 使用上面的直接連接字串更新此內容,替換 `__USER__` 和 `__PASSWORD__` 佔位符。
- 更新 `ALTER SCHEMA 'database_name' RENAME TO 'public';` 中的 `database_name`,使其與您 MySQL 連接字串中的 `database_name` 完全匹配。

在使用更新的憑證儲存配置檔案後,在同一個終端視窗中執行以下命令:

```terminal
pgloader config.load
```

您應該會看到類似以下的日誌,確認資料遷移成功:


:::note

```terminal

```
:::

## 4. 為 Prisma Postgres 配置您的 Prisma 專案

遷移資料後,您需要設定 Prisma 專案以使用 Prisma Postgres。這些步驟取決於您是否已經在使用 Prisma ORM。

### 如果您**之前沒有**使用 Prisma ORM

在專案目錄中執行 `npx prisma init` 來初始化 Prisma。這會建立一個包含 `schema.prisma` 檔案的 `prisma` 資料夾和 `.env` 檔案(如果尚不存在)。

在生成的 `.env` 檔案中,更新 `DATABASE_URL` 以匹配您在[步驟 1](/getting-started/prisma-postgres/import-from-existing-database-mysql#1-create-a-new-prisma-postgres-database) 中收到的 Prisma Postgres 直接連接字串:

```terminal  file=.env no-copy
DATABASE_URL="postgres://USER:PASSWORD@db.prisma.io:5432/?sslmode=require"
```

透過執行以下命令[內省](/orm/prisma-schema/introspection)您新遷移的資料庫:

```terminal
npx prisma db pull
```

此命令會使用代表遷移表的模型更新您的 `schema.prisma` 檔案,這樣您就可以開始使用 [Prisma Client](/orm/prisma-client) 查詢資料或使用 [Prisma Migrate](/orm/prisma-migrate/getting-started) 管理未來的變更。


恭喜!您已成功將 MySQL 資料庫遷移到 Prisma Postgres 並配置了您的 Prisma 專案。您的遷移教學現已完成。

:::note

要獲取使用 Prisma 和 Prisma Postgres 入門的綜合指南,請參閱[從頭開始使用 Prisma 和 Prisma Postgres](/getting-started/prisma-orm/quickstart/prisma-postgres)。

:::

### 如果您**已經**在使用 Prisma ORM

在您的 `schema.prisma` 檔案中,將 `datasource` 區塊中的 `provider` 從 `mysql` 更改為 `postgresql`:

```prisma file=schema.prisma
datasource db {
  // delete-start
  provider = "mysql"
  // delete-end
  // add-start
  provider = "postgres"
  // add-end
}
```

在生成的 `.env` 檔案中,更新 `DATABASE_URL` 以匹配您在[步驟 1](/getting-started/prisma-postgres/import-from-existing-database-mysql#1-create-a-new-prisma-postgres-database) 中收到的 Prisma Postgres 直接連接字串:

```terminal file=.env no-copy
DATABASE_URL="postgres://USER:PASSWORD@db.prisma.io:5432/?sslmode=require"
```

內省您新遷移的 Prisma Postgres 資料庫並生成 Prisma Client:

```terminal
npx prisma db pull
```

此命令會根據新的資料庫 schema 刷新您的 Prisma 模型。

如果您之前使用 [Prisma Migrate](/orm/prisma-migrate/getting-started):

- 刪除 `prisma` 目錄中現有的 `migrations` 資料夾。
- [基準化您的資料庫](/orm/prisma-migrate/workflows/baselining#baselining-a-database)以開始建立新的遷移。

恭喜!您已成功將 MySQL 資料庫遷移到 Prisma Postgres 並配置了您的 Prisma 專案。您的遷移教學現已完成。
