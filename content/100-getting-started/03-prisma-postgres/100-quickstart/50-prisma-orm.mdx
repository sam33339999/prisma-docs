[Prisma Postgres](/postgres) 是一個完全託管的 PostgreSQL 資料庫,可擴展至零並與 Prisma ORM 和 Prisma Studio 無縫整合。在本指南中,您將學習如何從頭開始設定新的 TypeScript 專案,使用 Prisma ORM 將其連接到 Prisma Postgres,並生成 Prisma Client 以實現輕鬆的型別安全資料庫存取。

## 2. 安裝所需的依賴項

安裝本快速入門所需的套件:

```terminal
npm install prisma @types/node --save-dev
npm install @prisma/client @prisma/adapter-pg dotenv
```

以下是每個套件的功能:

- **`prisma`** - 用於執行 `prisma init`、`prisma migrate` 和 `prisma generate` 等命令的 Prisma CLI
- **`@prisma/client`** - 用於查詢資料庫的 Prisma Client 函式庫
- **`@prisma/adapter-pg`** - 將 Prisma Client 連接到資料庫的 [`node-postgres` 驅動程式適配器](/orm/overview/databases/postgresql#using-the-node-postgres-driver)
- **`dotenv`** - 從 `.env` 檔案載入環境變數

## 3. 配置 ESM 支援

更新 `tsconfig.json` 以支援 ESM 相容性:

```json file=tsconfig.json
{
  "compilerOptions": {
    "module": "ESNext",
    "moduleResolution": "node",
    "target": "ES2023",
    "strict": true,
    "esModuleInterop": true,
    "ignoreDeprecations": "6.0"
  }
}
```

更新 `package.json` 以啟用 ESM:

```json file=package.json
{
  // add-start
  "type": "module",
  // add-end
}
```

## 4. 初始化 Prisma ORM 並建立 Prisma Postgres 資料庫

接下來,透過使用以下命令建立 [Prisma Schema](/orm/prisma-schema) 檔案來設定您的 Prisma ORM 專案:

```terminal
npx prisma init --db --output ../generated/prisma
```

:::info

在設定 Prisma Postgres 資料庫時,您需要回答幾個問題。選擇最接近您所在位置的地區以及一個容易記住的資料庫名稱。

:::

此命令會執行以下幾項操作:

- 建立一個 `prisma/` 目錄,其中包含一個 `schema.prisma` 檔案,內含您的資料庫連接和 schema 模型
- 建立一個新的 Prisma Postgres 資料庫(使用 `--db` 標誌時)
- 在根目錄中建立一個用於環境變數的 `.env` 檔案
- 在 `generated/prisma/` 目錄中生成 Prisma Client
- 建立一個用於 Prisma 配置的 `prisma.config.ts` 檔案

生成的 `prisma.config.ts` 檔案如下所示:

```typescript file=prisma.config.ts
import 'dotenv/config'
import { defineConfig, env } from 'prisma/config'

export default defineConfig({
  schema: 'prisma/schema.prisma',
  migrations: {
    path: 'prisma/migrations',
  },
  datasource: {
    url: env('DATABASE_URL'),
  },
})
```

生成的 schema 使用[以 ESM 為優先的 `prisma-client` generator](/orm/prisma-schema/overview/generators#prisma-client),並帶有自訂輸出路徑:

```prisma file=prisma/schema.prisma
generator client {
  provider = "prisma-client"
  output   = "../generated/prisma"
}

datasource db {
  provider = "postgresql"
}
```

## 5. 定義您的資料模型

開啟 `prisma/schema.prisma` 並新增以下模型:

```prisma file=prisma/schema.prisma
generator client {
  provider = "prisma-client"
  output   = "../generated/prisma"
}

datasource db {
  provider = "postgresql"
}

//add-start
model User {
  id    Int     @id @default(autoincrement())
  email String  @unique
  name  String?
  posts Post[]
}

model Post {
  id        Int     @id @default(autoincrement())
  title     String
  content   String?
  published Boolean @default(false)
  author    User    @relation(fields: [authorId], references: [id])
  authorId  Int
}
//add-end
```

## 6. 建立並套用您的第一個遷移

建立您的第一個遷移以設定資料庫表:

```terminal
npx prisma migrate dev --name init
```

此命令根據您的 schema 建立資料庫表。

現在執行以下命令來生成 Prisma Client:

```terminal
npx prisma generate
```

## 7. 實例化 Prisma Client

現在您已經安裝了所有依賴項,可以實例化 Prisma Client。您需要將 Prisma ORM 驅動程式適配器的實例傳遞給 `PrismaClient` 建構函式:

```typescript file=lib/prisma.ts
import "dotenv/config";
import { PrismaPg } from '@prisma/adapter-pg'
import { PrismaClient } from '../generated/prisma/client'

const connectionString = `${process.env.DATABASE_URL}`

const adapter = new PrismaPg({ connectionString })
const prisma = new PrismaClient({ adapter })

export { prisma }
```

:::tip

如果您需要從邊緣運行時(Cloudflare Workers、Vercel Edge Functions 等)透過 HTTP 查詢資料庫,請使用 [Prisma Postgres serverless 驅動程式](/postgres/database/serverless-driver#use-with-prisma-orm)。

:::

## 8. 撰寫您的第一個查詢

建立一個 `script.ts` 檔案來測試您的設定:

```typescript file=script.ts
import { prisma } from './lib/prisma'

async function main() {
  // Create a new user with a post
  const user = await prisma.user.create({
    data: {
      name: 'Alice',
      email: 'alice@prisma.io',
      posts: {
        create: {
          title: 'Hello World',
          content: 'This is my first post!',
          published: true,
        },
      },
    },
    include: {
      posts: true,
    },
  })
  console.log('Created user:', user)

  // Fetch all users with their posts
  const allUsers = await prisma.user.findMany({
    include: {
      posts: true,
    },
  })
  console.log('All users:', JSON.stringify(allUsers, null, 2))
}

main()
  .then(async () => {
    await prisma.$disconnect()
  })
  .catch(async (e) => {
    console.error(e)
    await prisma.$disconnect()
    process.exit(1)
  })
```

執行腳本:

```terminal
npx tsx script.ts
```

您應該會看到建立的使用者和所有使用者都列印到控制台!
