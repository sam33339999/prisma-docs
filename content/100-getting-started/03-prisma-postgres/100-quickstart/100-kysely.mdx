[Kysely](https://kysely.dev) 是一個型別安全的 TypeScript SQL 查詢建構器,提供 TypeScript 支援和用於建構 SQL 查詢的流暢 API。在本指南中,您將學習如何將 Kysely 連接到 [Prisma Postgres](/postgres) 並開始使用完整的型別安全查詢資料庫。

## 先決條件

- Node.js 版本 14 或更高
- TypeScript 版本 4.6 或更高(建議使用 5.4+ 以改進型別推斷,使用 5.9+ 以獲得更好的編譯效能)
- 在 `tsconfig.json` 中啟用嚴格模式以實現 Kysely 的型別安全

## 1. 建立新專案

為您的專案建立一個新目錄並使用 npm 初始化:

```terminal
mkdir kysely-quickstart
cd kysely-quickstart
npm init -y
```

安裝 TypeScript 並初始化它:

```terminal
npm install --save-dev typescript
npx tsc --init
```

## 2. 配置 TypeScript

Kysely 需要 TypeScript 的嚴格模式以實現適當的型別安全。更新您的 `tsconfig.json` 檔案:

```json file=tsconfig.json
{
  // ...
  "compilerOptions": {
    // ...
    // add-start
    "strict": true,
    "allowImportingTsExtensions": true,
    "noEmit": true
    // add-end
    // ...
  }
  // ...
}
```

:::note

**必須**設定 `strict: true` 才能使 Kysely 的型別安全正常運作。

:::

在您的 `package.json` 中,將 `type` 設定為 `module`:

```json
{
// ...
// add-start
"type": "module"
// add-end
// ...
}
```

## 3. 建立 Prisma Postgres 資料庫

您可以使用 `create-db` CLI 工具建立 Prisma Postgres 資料庫。按照以下步驟建立您的 Prisma Postgres 資料庫:

```terminal

```

建立一個 `.env` 檔案並新增輸出中的連接字串:

```env file=.env
DATABASE_URL="postgresql://hostname:password@db.prisma.io:5432/postgres?sslmode=require"
```

:::warning

**永遠不要將 `.env` 檔案提交到版本控制。** 將 `.env` 新增到您的 `.gitignore` 檔案以保持憑證安全。

建立的資料庫是臨時的,除非被認領,否則將在 24 小時內刪除。認領會將資料庫移至您的 [Prisma Data Platform](https://console.prisma.io) 帳戶。訪問輸出中的認領 URL 以保留您的資料庫。

:::note

要了解更多關於 `create-db` CLI 工具的資訊,請參閱 [create-db 文件](/postgres/introduction/npx-create-db)。

## 4. 安裝依賴項

安裝 Kysely 和 PostgreSQL 驅動程式:

```terminal
npm install kysely pg dotenv
npm install --save-dev @types/pg tsx
```

**套件說明:**
- `kysely`: 型別安全的 SQL 查詢建構器
- `pg`: Node.js 的 PostgreSQL 驅動程式(Kysely 的 PostgresDialect 需要)
- `dotenv`: 從 `.env` 檔案載入環境變數
- `@types/pg`: pg 驅動程式的 TypeScript 型別定義
- `tsx`: 用於直接執行 `.ts` 檔案的 TypeScript 執行引擎

## 5. 定義資料庫型別

建立一個 `src/types.ts` 檔案來定義您的資料庫 schema 型別:

```typescript file=src/types.ts
import type { Generated } from "kysely";

export interface Database {
  users: UsersTable;
}

export interface UsersTable {
  id: Generated<number>;
  email: string;
  name: string | null;
}
```

## 6. 配置資料庫連接

建立一個 `src/database.ts` 檔案,使用您的 Prisma Postgres 連接實例化 Kysely:

```typescript file=src/database.ts
import 'dotenv/config'
import type { Database } from './types.ts'
import { Pool } from 'pg'
import { Kysely, PostgresDialect } from 'kysely'

// Parse DATABASE_URL into connection parameters
function parseConnectionString(url: string) {
  const parsed = new URL(url)
  return {
    host: parsed.hostname,
    port: parseInt(parsed.port),
    user: parsed.username,
    password: parsed.password,
    database: parsed.pathname.slice(1), // Remove leading '/'
  }
}

const connectionParams = parseConnectionString(process.env.DATABASE_URL!)

const dialect = new PostgresDialect({
  pool: new Pool({
    ...connectionParams,
    ssl: true,
    max: 10,
  })
})

// Database interface is passed to Kysely's constructor, and from now on, Kysely
// knows your database structure.
// Dialect is passed to Kysely's constructor, and from now on, Kysely knows how
// to communicate with your database.
export const db = new Kysely<Database>({
  dialect,
})
```

## 7. 執行查詢

建立一個 `src/script.ts` 檔案:

```typescript file=src/script.ts
import { db } from './database.ts'

async function main() {
  // Create the users table
  await db.schema
    .createTable('users')
    .ifNotExists()
    .addColumn('id', 'serial', (col) => col.primaryKey())
    .addColumn('email', 'varchar(255)', (col) => col.notNull().unique())
    .addColumn('name', 'varchar(255)')
    .execute()

  // Insert a user
  const user = await db
    .insertInto('users')
    .values({
      email: 'alice@prisma.io',
      name: 'Alice',
    })
    .returningAll()
    .executeTakeFirstOrThrow()

  console.log('Created user:', user)

  // Query all users
  const users = await db
    .selectFrom('users')
    .selectAll()
    .execute()

  console.log('All users:', users)
}

main()
  .then(async () => {
    await db.destroy()
  })
  .catch(async (error) => {
    console.error('Error:', error)
    await db.destroy()
    process.exit(1)
  })
```

執行腳本:

```terminal
npx tsx src/script.ts
```

您應該會收到以下輸出:

```terminal
Created user: { id: 1, email: 'alice@prisma.io', name: 'Alice' }
All users: [ { id: 1, email: 'alice@prisma.io', name: 'Alice' } ]
```
