[Drizzle ORM](https://orm.drizzle.team) 是一個 TypeScript ORM。在本指南中,您將學習如何將 Drizzle ORM 連接到 [Prisma Postgres](/postgres)。

## 先決條件

- Node.js 版本 16 或更高
- TypeScript 版本 5.0 或更高

## 1. 建立新專案

為您的專案建立一個新目錄並使用 npm 初始化:

```terminal
mkdir drizzle-quickstart
cd drizzle-quickstart
npm init -y
```

安裝 TypeScript 並初始化它:

```terminal
npm install --save-dev typescript
npx tsc --init
```

在您的 `package.json` 中,將 `type` 設定為 `module`:

```json file=package.json
{
  // ...
  // add-start
  "type": "module"
  // add-end
  // ...
}
```

## 2. 建立 Prisma Postgres 資料庫

您可以使用 `create-db` CLI 工具建立 Prisma Postgres 資料庫。按照以下步驟建立您的 Prisma Postgres 資料庫:

```terminal
npx create-db
```

然後 CLI 工具應該會輸出:


建立一個 `.env` 檔案並新增輸出中的連接字串:

```env file=.env
DATABASE_URL="postgresql://hostname:password@db.prisma.io:5432/postgres?sslmode=require"
```

:::warning

**永遠不要將 `.env` 檔案提交到版本控制。** 將 `.env` 新增到您的 `.gitignore` 檔案以保持憑證安全。

:::

建立的資料庫是臨時的,除非被認領,否則將在 24 小時內刪除。認領會將資料庫移至您的 [Prisma Data Platform](https://console.prisma.io) 帳戶。訪問輸出中的認領 URL 以保留您的資料庫。

:::note

要了解更多關於 `create-db` CLI 工具的資訊,請參閱 [create-db 文件](/postgres/introduction/npx-create-db)。

:::

## 3. 安裝依賴項

安裝 Drizzle ORM 和 PostgreSQL 驅動程式:

```terminal
npm install drizzle-orm pg dotenv
npm install --save-dev drizzle-kit @types/pg tsx
```

**套件說明:**
- `drizzle-orm`: 輕量級的 TypeScript ORM
- `pg`: Node.js 的 PostgreSQL 驅動程式
- `dotenv`: 從 `.env` 檔案載入環境變數
- `drizzle-kit`: 用於遷移和 schema 管理的 CLI 工具
- `@types/pg`: pg 驅動程式的 TypeScript 型別定義
- `tsx`: 用於直接執行 `.ts` 檔案的 TypeScript 執行引擎

## 4. 執行查詢

建立一個 `src/script.ts` 檔案:

```typescript file=src/script.ts
import 'dotenv/config'
import { drizzle } from 'drizzle-orm/node-postgres'
import { Pool } from 'pg'

const pool = new Pool({
  connectionString: process.env.DATABASE_URL,
})

const db = drizzle({ client: pool })

async function main() {
  const result = await db.execute('select 1')
  console.log('Query result:', result)
}

main()
  .then(async () => {
    await pool.end()
    console.log('Connection closed')
  })
  .catch(async (error) => {
    console.error('Error:', error)
    await pool.end()
    process.exit(1)
  })
```

執行腳本:

```terminal
npx tsx src/script.ts
```
