[TypeORM](https://typeorm.io) 是一個 TypeScript ORM。在本指南中,您將學習如何將 TypeORM 連接到 [Prisma Postgres](/postgres)。

## 先決條件

- Node.js 版本 16 或更高
- TypeScript 版本 4.5 或更高

## 1. 生成 TypeORM 專案

使用 TypeORM CLI 生成一個入門專案:

```terminal
npx typeorm init --name typeorm-quickstart --database postgres
```

此命令將生成一個具有以下結構的新專案:

```
typeorm-quickstart
├── src
│   ├── entity
│   │   └── User.ts       # Sample entity
│   ├── migration         # Migrations folder
│   ├── data-source.ts    # Data source configuration
│   └── index.ts          # Application entry point
├── .gitignore
├── package.json
├── README.md
└── tsconfig.json
```

## 2. 安裝依賴項

導航到專案目錄並安裝依賴項:

```terminal
cd typeorm-quickstart
npm install
```

安裝 dotenv 以載入環境變數:

```terminal
npm install dotenv
```

## 3. 建立 Prisma Postgres 資料庫

您可以使用 `create-db` CLI 工具建立 Prisma Postgres 資料庫。按照以下步驟建立您的 Prisma Postgres 資料庫:

```terminal
npx create-db
```

然後 CLI 工具應該會輸出:

```terminal
┌  🚀 Creating a Prisma Postgres database
│
│  Provisioning a temporary database in us-east-1...
│
│  It will be automatically deleted in 24 hours, but you can claim it.
│
◇  Database created successfully!
│
│
●  Database Connection
│
│
│    Connection String:
│
│    postgresql://hostname:password@db.prisma.io:5432/postgres?sslmode=require
│
│
◆  Claim Your Database
│
│    Keep your database for free:
│
│    https://create-db.prisma.io/claim?CLAIM_CODE
│
│    Database will be deleted on 11/18/2025, 1:55:39 AM if not claimed.
│

```

建立一個 `.env` 檔案並新增輸出中的連接字串:

```env file=.env
DATABASE_URL="postgresql://hostname:password@db.prisma.io:5432/postgres?sslmode=require"
```

:::warning

**永遠不要將 `.env` 檔案提交到版本控制。** 將 `.env` 新增到您的 `.gitignore` 檔案以保持憑證安全。

:::

建立的資料庫是臨時的,除非被認領,否則將在 24 小時內刪除。認領會將資料庫移至您的 [Prisma Data Platform](https://console.prisma.io) 帳戶。訪問輸出中的認領 URL 以保留您的資料庫。

:::note

要了解更多關於 `create-db` CLI 工具的資訊,請參閱 [create-db 文件](/postgres/introduction/npx-create-db)。

:::

## 4. 配置資料庫連接

更新 `src/data-source.ts` 檔案以使用您的 Prisma Postgres 連接:

```typescript file=src/data-source.ts
import "reflect-metadata"
// add-start
import "dotenv/config";
// add-end
import { DataSource } from "typeorm"
import { User } from "./entity/User"

// add-start
// Parse DATABASE_URL into connection parameters
function parseConnectionString(url: string) {
  const parsed = new URL(url)
  return {
    host: parsed.hostname,
    port: parseInt(parsed.port),
    username: parsed.username,
    password: parsed.password,
    database: parsed.pathname.slice(1), // Remove leading '/'
  }
}

const connectionParams = parseConnectionString(process.env.DATABASE_URL!)
// add-end

export const AppDataSource = new DataSource({
  type: "postgres",
  // delete-start
  host: "localhost",
  port: 5432,
  username: "test",
  password: "test",
  database: "test",
  // delete-end
  // add-start
  ...connectionParams,
  ssl: true,
  // add-end
  synchronize: true,
  logging: false,
  entities: [User],
  migrations: [],
  subscribers: [],
})
```

## 5. 執行應用程式

啟動應用程式:

```terminal
npm start
```

您應該會看到輸出指示連接成功,並且新使用者已插入到資料庫中:

```terminal
Inserting a new user into the database...
Saved a new user with id: 1
Loading users from the database...
Loaded users:  [ User { id: 1, firstName: 'Timber', lastName: 'Saw', age: 25 } ]
```

您已成功將 TypeORM 連接到 Prisma Postgres!要了解更多進階功能,如實體、遷移和查詢,請參閱 [TypeORM 文件](https://typeorm.io/docs/getting-started)。
