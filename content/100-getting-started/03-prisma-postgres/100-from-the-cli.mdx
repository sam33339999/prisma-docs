## 1. 組織您的專案目錄

:::note

如果您在希望專案所在的資料夾內執行了 `prisma init --db` 命令,可以跳過此步驟並[繼續下一節](/getting-started/prisma-postgres/from-the-cli#2-set-up-your-project)。

:::

如果您在預期的專案目錄之外執行了該命令(例如,在您的主資料夾或其他位置),則需要將生成的 `prisma` 資料夾和 `.env` 檔案移動到專用的專案目錄中。

建立一個新資料夾(例如 `hello-prisma`),您希望專案在此處存放,並將必要的檔案移動到其中:

```terminal
mkdir hello-prisma
mv .env ./hello-prisma/
mv prisma ./hello-prisma/
```

導航到您的專案資料夾:

```terminal
cd ./hello-prisma
```

現在您的專案已經在正確的位置,繼續進行設定。

## 2. 設定您的專案

### 2.1. 設定 TypeScript

初始化 TypeScript 專案並將 Prisma CLI 新增為開發依賴項:

```terminal
npm init -y
npm install typescript tsx @types/node @types/pg --save-dev
```

這會建立一個包含 TypeScript 應用程式初始設定的 `package.json` 檔案。

接下來,在專案中使用 `tsconfig.json` 檔案初始化 TypeScript:

```terminal
npx tsc --init
```

### 2.2. 配置 ESM 支援

更新 `tsconfig.json` 以支援 ESM 相容性:

```json file=tsconfig.json
{
  "compilerOptions": {
    "module": "ESNext",
    "moduleResolution": "node",
    "target": "ES2023",
    "strict": true,
    "esModuleInterop": true,
    "ignoreDeprecations": "6.0"
  }
}
```

更新 `package.json` 以啟用 ESM:

```json file=package.json
{
  // add-start
  "type": "module",
  // add-end
}
```

### 2.3. 設定 Prisma ORM

安裝使用 Prisma Postgres 所需的依賴項:

```terminal
npm install prisma --save-dev
npm install @prisma/client @prisma/adapter-pg pg dotenv
```

以下是每個套件的功能:

- **`prisma`** - 用於執行 `prisma migrate` 和 `prisma generate` 等命令的 Prisma CLI
- **`@prisma/client`** - 用於查詢資料庫的 Prisma Client 函式庫
- **`@prisma/adapter-pg`** - 將 Prisma Client 連接到資料庫的 [`node-postgres` 驅動程式適配器](/orm/overview/databases/postgresql#using-the-node-postgres-driver)
- **`pg`** - node-postgres 資料庫驅動程式
- **`@types/pg`** - node-postgres 的 TypeScript 型別定義
- **`dotenv`** - 從 `.env` 檔案載入環境變數

### 2.4. 檢查生成的 prisma.config.ts

`prisma init --db` 命令自動建立了一個如下所示的 `prisma.config.ts` 檔案:

```typescript file=prisma.config.ts
import 'dotenv/config'
import { defineConfig, env } from 'prisma/config'

export default defineConfig({
  schema: 'prisma/schema.prisma',
  migrations: {
    path: 'prisma/migrations',
  },
  datasource: {
    url: env('DATABASE_URL'),
  },
})
```

### 2.5. 建立一個用於查詢資料庫的腳本

在根目錄中建立一個 `index.ts` 檔案,這將用於使用 Prisma ORM 查詢您的應用程式:

```terminal
touch index.ts
```

## 3. 遷移資料庫 schema

更新您的 `prisma/schema.prisma` 檔案以包含 `User` 和 `Post` 模型:

```prisma file=prisma/schema.prisma
generator client {
  provider = "prisma-client"
  output   = "../generated/prisma"
}

datasource db {
  provider = "postgresql"
}

model User {
  id    Int     @id @default(autoincrement())
  email String  @unique
  name  String?
  posts Post[]
}

model Post {
  id        Int     @id @default(autoincrement())
  title     String
  content   String?
  published Boolean @default(false)
  author    User    @relation(fields: [authorId], references: [id])
  authorId  Int
}
```

新增模型後,使用 [Prisma Migrate](/orm/prisma-migrate) 遷移資料庫:

```terminal
npx prisma migrate dev --name init
```

此命令根據您的 schema 建立資料庫表。

現在執行以下命令來生成 Prisma Client:

```terminal
npx prisma generate
```

## 4. 使用 Prisma ORM 發送查詢

### 4.1. 實例化 Prisma Client

建立一個 `lib/prisma.ts` 檔案,使用驅動程式適配器實例化 Prisma Client:

```typescript file=lib/prisma.ts
import "dotenv/config";
import { PrismaPg } from '@prisma/adapter-pg'
import { PrismaClient } from '../generated/prisma/client'

const connectionString = `${process.env.DATABASE_URL}`

const adapter = new PrismaPg({ connectionString })
const prisma = new PrismaClient({ adapter })

export { prisma }
```

:::tip

如果您需要從邊緣運行時(Cloudflare Workers、Vercel Edge Functions 等)透過 HTTP 查詢資料庫,請使用 [Prisma Postgres serverless 驅動程式](/postgres/database/serverless-driver#use-with-prisma-orm)。

:::

### 4.2. 撰寫您的第一個查詢

將以下範本貼到 `index.ts` 中:

```ts file=index.ts
import { prisma } from './lib/prisma'

async function main() {
  // ... you will write your Prisma ORM queries here
}

main()
  .then(async () => {
    await prisma.$disconnect()
  })
  .catch(async (e) => {
    console.error(e)
    await prisma.$disconnect()
    process.exit(1)
  })
```

此程式碼包含一個在腳本結尾被調用的 `main` 函式。它還實例化了 `PrismaClient`,您將使用它向資料庫發送查詢。

### 4.3. 建立一筆新的 `User` 記錄

讓我們從一個小查詢開始,在資料庫中建立一筆新的 `User` 記錄,並將結果物件記錄到控制台。將以下程式碼新增到您的 `index.ts` 檔案中:

```ts file=index.ts
import { prisma } from './lib/prisma'

async function main() {
  // add-start
  const user = await prisma.user.create({
    data: {
      name: 'Alice',
      email: 'alice@prisma.io',
    },
  })
  console.log(user)
  // add-end
}

main()
  .then(async () => {
    await prisma.$disconnect()
  })
  .catch(async (e) => {
    console.error(e)
    await prisma.$disconnect()
    process.exit(1)
  })
```

### 4.4. 檢索所有 `User` 記錄

Prisma ORM 提供各種查詢來從資料庫讀取資料。在本節中,您將使用 `findMany` 查詢,該查詢會返回給定模型在資料庫中的_所有_記錄。

刪除先前的 Prisma ORM 查詢,並改為新增新的 `findMany` 查詢:

```ts file=index.ts
import { prisma } from './lib/prisma'

async function main() {
  // add-start
  const users = await prisma.user.findMany()
  console.log(users)
  // add-end
}

main()
  .then(async () => {
    await prisma.$disconnect()
  })
  .catch(async (e) => {
    console.error(e)
    await prisma.$disconnect()
    process.exit(1)
  })
```

### 4.5. 探索關聯查詢

Prisma ORM 的主要功能之一是易於處理[關聯](/orm/prisma-schema/data-model/relations)。在本節中,您將學習如何在巢狀寫入查詢中建立 `User` 和 `Post` 記錄。之後,您將看到如何使用 `include` 選項從資料庫檢索關聯。

首先,調整您的腳本以包含巢狀查詢:

```ts file=index.ts
import { prisma } from './lib/prisma'

async function main() {
  // add-start
  const user = await prisma.user.create({
    data: {
      name: 'Bob',
      email: 'bob@prisma.io',
      posts: {
        create: [
          {
            title: 'Hello World',
            published: true
          },
          {
            title: 'My second post',
            content: 'This is still a draft'
          }
        ],
      },
    },
  })
  console.log(user)
  // add-end
}

main()
  .then(async () => {
    await prisma.$disconnect()
  })
  .catch(async (e) => {
    console.error(e)
    await prisma.$disconnect()
    process.exit(1)
  })
```

透過再次執行腳本來執行查詢:


</cmd>

</CodeWithResult>

為了同時檢索屬於 `User` 的 `Post` 記錄,您可以透過 `posts` 關聯欄位使用 `include` 選項:

```ts file=index.ts
import { prisma } from './lib/prisma'

async function main() {
// add-start
  const usersWithPosts = await prisma.user.findMany({
    include: {
      posts: true,
    },
  })
  console.dir(usersWithPosts, { depth: null })
  // add-end
}

main()
  .then(async () => {
    await prisma.$disconnect()
  })
  .catch(async (e) => {
    console.error(e)
    await prisma.$disconnect()
    process.exit(1)
  })
```

## 後續步驟

您剛剛初步體驗了基本的 Prisma Postgres 設定。如果您想探索更複雜的查詢,例如[新增快取功能](/postgres/database/caching#setting-up-caching-in-prisma-postgres),請查看官方的[快速入門](/getting-started/prisma-orm/quickstart/prisma-postgres)。

### 在 Prisma Studio 中查看和編輯資料

Prisma ORM 附帶內建 GUI,用於查看和編輯資料庫中的資料。您可以使用以下命令開啟它:

```terminal
npx prisma studio --config ./prisma.config.ts
```

使用 Prisma Postgres,您也可以在專案中選擇 **Studio** 分頁,直接在 [Console](https://console.prisma.io) 內使用 Prisma Studio。


### 使用 Next.js 建置全端應用程式

了解如何在全端應用程式中使用 Prisma Postgres:

- [使用 Next.js 15 建置全端應用程式](/guides/nextjs)
- [Next.js 15 範例應用程式](https://github.com/prisma/nextjs-prisma-postgres-demo)(包含身份驗證)


### 探索可直接執行的範例

查看 GitHub 上的 [`prisma-examples`](https://github.com/prisma/prisma-examples/) 儲存庫,了解如何將 Prisma ORM 與您喜愛的函式庫一起使用。該儲存庫包含 Express、NestJS、GraphQL 的範例,以及 Next.js 和 Vue.js 的全端範例等等。

這些範例預設使用 SQLite,但您可以按照專案 README 中的說明,只需幾個簡單的步驟即可切換到 Prisma Postgres。
