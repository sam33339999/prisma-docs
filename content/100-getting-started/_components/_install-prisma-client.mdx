接著執行 `prisma generate`，它會讀取您的 Prisma schema 並產生 Prisma Client：

```terminal
npx prisma generate
```

:::note 小知識

當您執行 `prisma generate` 時，會根據您的 Prisma schema 產生對應的程式碼（TypeScript 型別、方法、查詢）。每當您修改 Prisma schema 時，都需要執行 `prisma generate` 來更新 Prisma Client。

每當您更新 Prisma schema 時，也需要使用 `prisma migrate dev` 或 `prisma db push` 來更新資料庫結構描述。這些指令也會自動執行 `prisma generate`。

:::
