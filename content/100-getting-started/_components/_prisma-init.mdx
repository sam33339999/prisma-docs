## {props.stepNumber ? `${props.stepNumber}. ` : ''}初始化 Prisma

現在您可以透過加上 `npx` 前綴來呼叫 Prisma CLI：

```terminal
npx prisma
```

接下來，使用以下指令建立您的 [Prisma Schema](/orm/prisma-schema) 檔案來設定 Prisma ORM 專案：

{props.database === 'prisma-postgres' ? (
<>
<CodeBlock language="terminal">
{`npx prisma init --db --output ../generated/prisma`}
</CodeBlock>

:::info

在設定 Prisma Postgres 資料庫時，您需要回答幾個問題。請選擇最靠近您所在位置的區域，以及一個容易記住的資料庫名稱。

:::

這個指令會建立：

- 一個 `prisma/` 目錄，內含 `schema.prisma` 檔案，其中包含您的資料庫連線和結構描述模型
- 一個新的 Prisma Postgres 資料庫（使用 `--db` 旗標時）
- 根目錄中的 `.env` 檔案，用於環境變數
- 一個 `generated/prisma/` 目錄，用於存放產生的 Prisma Client

產生的 schema 使用現代化的 `prisma-client` 產生器與自訂輸出路徑：

<CodeBlock language="prisma" metastring="file=prisma/schema.prisma">
{`generator client {
  provider = "prisma-client"
  output   = "../generated/prisma"
}

datasource db {
  provider = "postgresql"
}`}
</CodeBlock>
</>
) : (
<>
<CodeBlock language="terminal">
{`npx prisma init --datasource-provider ${props.datasource?.toLowerCase() || props.database} --output ../generated/prisma`}
</CodeBlock>

這個指令會執行以下動作：

- 建立一個名為 `prisma` 的新目錄，其中包含一個名為 `schema.prisma` 的檔案，內含您的資料庫連線變數和結構描述模型的 Prisma Schema。
- 分別將 `datasource` 設定為 {props.datasource || props.database}，並將輸出設定為自訂位置。
- 在專案根目錄中建立 [`.env` 檔案](/orm/more/development-environment/environment-variables)，用於定義環境變數（例如您的資料庫連線）

請注意，`prisma init` 建立的預設 schema 使用 PostgreSQL 作為 `provider`。如果您沒有使用 `datasource-provider` 選項指定提供者，則需要編輯 `datasource` 區塊改為使用 <code>{(props.datasource || props.database)?.toLowerCase()}</code> 提供者：

<CodeBlock language="prisma" metastring="file=prisma/schema.prisma">
{`datasource db {
  //edit-next-line
  provider = "${(props.datasource || props.database)?.toLowerCase()}"
  url      = env("DATABASE_URL")
}`}
</CodeBlock>
</>
)}
