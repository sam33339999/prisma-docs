<BorderBox>

[**Prisma ORM**](/orm/overview/introduction/what-is-prisma) 是一個開源 ORM,提供快速、型別安全的 Postgres、MySQL、SQLite 等資料庫存取,並可在 Node.js、Bun 和 Deno 上順暢運行。

```terminal always-copy
npx prisma init --db
```
</BorderBox >
      

<BorderBox>

[**Prisma Postgres**](/postgres) 是一個全託管的 PostgreSQL 資料庫,可縮放至零、整合 Prisma ORM 和 Prisma Studio,並提供慷慨的免費方案。

```terminal always-copy
npx create-db
```
</BorderBox >
      
</List>
